# Krateo Blueprint — AWS Acmpca Certificate

> Generated by `tools/ackgen` from the ACK `Certificate` CRD (`acmpca.services.k8s.aws`).

Provisions an AWS Acmpca **Certificate** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
acmpca controller. The chart renders a native `acmpca.services.k8s.aws/v1alpha1` `Certificate`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsAcmpcaCertificate` Composition you create
becomes an AWS Certificate.

## Prerequisites

- **ACK acmpca controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-acmpca-controller \
    oci://public.ecr.aws/aws-controllers-k8s/acmpca-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Certificate spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-acmpca-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsAcmpcaCertificate type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsAcmpcaCertificate` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsacmpcacertificates`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-acmpca-certificate`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsAcmpcaCertificate
metadata:
  name: my-certificate
  namespace: aws-acmpca-system
spec:
  region: eu-west-1
  # ... ACK Certificate spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsacmpcacertificates.composition.krateo.io -n aws-acmpca-system
kubectl get certificates.acmpca.services.k8s.aws -A
```
