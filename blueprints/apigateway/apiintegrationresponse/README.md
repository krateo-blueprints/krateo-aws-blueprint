# Krateo Blueprint — AWS Apigateway APIIntegrationResponse

> Generated by `tools/ackgen` from the ACK `APIIntegrationResponse` CRD (`apigateway.services.k8s.aws`).

Provisions an AWS Apigateway **APIIntegrationResponse** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
apigateway controller. The chart renders a native `apigateway.services.k8s.aws/v1alpha1` `APIIntegrationResponse`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsApigatewayApiintegrationresponse` Composition you create
becomes an AWS APIIntegrationResponse.

## Prerequisites

- **ACK apigateway controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-apigateway-controller \
    oci://public.ecr.aws/aws-controllers-k8s/apigateway-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK APIIntegrationResponse spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-apigateway-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsApigatewayApiintegrationresponse type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsApigatewayApiintegrationresponse` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsapigatewayapiintegrationresponses`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-apigateway-apiintegrationresponse`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsApigatewayApiintegrationresponse
metadata:
  name: my-apiintegrationresponse
  namespace: aws-apigateway-system
spec:
  region: eu-west-1
  # ... ACK APIIntegrationResponse spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsapigatewayapiintegrationresponses.composition.krateo.io -n aws-apigateway-system
kubectl get apiintegrationresponses.apigateway.services.k8s.aws -A
```
