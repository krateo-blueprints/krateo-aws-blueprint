# Krateo Blueprint — AWS Apigateway Authorizer

> Generated by `tools/ackgen` from the ACK `Authorizer` CRD (`apigateway.services.k8s.aws`).

Provisions an AWS Apigateway **Authorizer** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
apigateway controller. The chart renders a native `apigateway.services.k8s.aws/v1alpha1` `Authorizer`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsApigatewayAuthorizer` Composition you create
becomes an AWS Authorizer.

## Prerequisites

- **ACK apigateway controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-apigateway-controller \
    oci://public.ecr.aws/aws-controllers-k8s/apigateway-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Authorizer spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-apigateway-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsApigatewayAuthorizer type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsApigatewayAuthorizer` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsapigatewayauthorizers`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-apigateway-authorizer`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsApigatewayAuthorizer
metadata:
  name: my-authorizer
  namespace: aws-apigateway-system
spec:
  region: eu-west-1
  # ... ACK Authorizer spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsapigatewayauthorizers.composition.krateo.io -n aws-apigateway-system
kubectl get authorizers.apigateway.services.k8s.aws -A
```
