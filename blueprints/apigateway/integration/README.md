# Krateo Blueprint — AWS Apigateway Integration

> Generated by `tools/ackgen` from the ACK `Integration` CRD (`apigateway.services.k8s.aws`).

Provisions an AWS Apigateway **Integration** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
apigateway controller. The chart renders a native `apigateway.services.k8s.aws/v1alpha1` `Integration`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsApigatewayIntegration` Composition you create
becomes an AWS Integration.

## Prerequisites

- **ACK apigateway controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-apigateway-controller \
    oci://public.ecr.aws/aws-controllers-k8s/apigateway-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Integration spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-apigateway-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsApigatewayIntegration type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsApigatewayIntegration` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsapigatewayintegrations`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-apigateway-integration`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsApigatewayIntegration
metadata:
  name: my-integration
  namespace: aws-apigateway-system
spec:
  region: eu-west-1
  # ... ACK Integration spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsapigatewayintegrations.composition.krateo.io -n aws-apigateway-system
kubectl get integrations.apigateway.services.k8s.aws -A
```
