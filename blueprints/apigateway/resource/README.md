# Krateo Blueprint — AWS Apigateway Resource

> Generated by `tools/ackgen` from the ACK `Resource` CRD (`apigateway.services.k8s.aws`).

Provisions an AWS Apigateway **Resource** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
apigateway controller. The chart renders a native `apigateway.services.k8s.aws/v1alpha1` `Resource`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsApigatewayResource` Composition you create
becomes an AWS Resource.

## Prerequisites

- **ACK apigateway controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-apigateway-controller \
    oci://public.ecr.aws/aws-controllers-k8s/apigateway-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Resource spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-apigateway-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsApigatewayResource type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsApigatewayResource` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsapigatewayresources`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-apigateway-resource`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsApigatewayResource
metadata:
  name: my-resource
  namespace: aws-apigateway-system
spec:
  region: eu-west-1
  # ... ACK Resource spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsapigatewayresources.composition.krateo.io -n aws-apigateway-system
kubectl get resources.apigateway.services.k8s.aws -A
```
