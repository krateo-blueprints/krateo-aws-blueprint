# Krateo Blueprint — AWS Apigatewayv2 APIMapping

> Generated by `tools/ackgen` from the ACK `APIMapping` CRD (`apigatewayv2.services.k8s.aws`).

Provisions an AWS Apigatewayv2 **APIMapping** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
apigatewayv2 controller. The chart renders a native `apigatewayv2.services.k8s.aws/v1alpha1` `APIMapping`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsApigatewayv2Apimapping` Composition you create
becomes an AWS APIMapping.

## Prerequisites

- **ACK apigatewayv2 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-apigatewayv2-controller \
    oci://public.ecr.aws/aws-controllers-k8s/apigatewayv2-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK APIMapping spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-apigatewayv2-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsApigatewayv2Apimapping type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsApigatewayv2Apimapping` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsapigatewayv2apimappings`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-apigatewayv2-apimapping`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsApigatewayv2Apimapping
metadata:
  name: my-apimapping
  namespace: aws-apigatewayv2-system
spec:
  region: eu-west-1
  # ... ACK APIMapping spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsapigatewayv2apimappings.composition.krateo.io -n aws-apigatewayv2-system
kubectl get apimappings.apigatewayv2.services.k8s.aws -A
```
