# Krateo Blueprint — AWS Apigatewayv2 DomainName

> Generated by `tools/ackgen` from the ACK `DomainName` CRD (`apigatewayv2.services.k8s.aws`).

Provisions an AWS Apigatewayv2 **DomainName** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
apigatewayv2 controller. The chart renders a native `apigatewayv2.services.k8s.aws/v1alpha1` `DomainName`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsApigatewayv2Domainname` Composition you create
becomes an AWS DomainName.

## Prerequisites

- **ACK apigatewayv2 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-apigatewayv2-controller \
    oci://public.ecr.aws/aws-controllers-k8s/apigatewayv2-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK DomainName spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-apigatewayv2-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsApigatewayv2Domainname type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsApigatewayv2Domainname` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsapigatewayv2domainnames`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-apigatewayv2-domainname`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsApigatewayv2Domainname
metadata:
  name: my-domainname
  namespace: aws-apigatewayv2-system
spec:
  region: eu-west-1
  # ... ACK DomainName spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsapigatewayv2domainnames.composition.krateo.io -n aws-apigatewayv2-system
kubectl get domainnames.apigatewayv2.services.k8s.aws -A
```
