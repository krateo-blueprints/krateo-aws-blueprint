# Krateo Blueprint — AWS Applicationautoscaling ScalableTarget

> Generated by `tools/ackgen` from the ACK `ScalableTarget` CRD (`applicationautoscaling.services.k8s.aws`).

Provisions an AWS Applicationautoscaling **ScalableTarget** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
applicationautoscaling controller. The chart renders a native `applicationautoscaling.services.k8s.aws/v1alpha1` `ScalableTarget`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsApplicationautoscalingScalabletarget` Composition you create
becomes an AWS ScalableTarget.

## Prerequisites

- **ACK applicationautoscaling controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-applicationautoscaling-controller \
    oci://public.ecr.aws/aws-controllers-k8s/applicationautoscaling-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ScalableTarget spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-applicationautoscaling-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsApplicationautoscalingScalabletarget type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsApplicationautoscalingScalabletarget` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsapplicationautoscalingscalabletargets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-applicationautoscaling-scalabletarget`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsApplicationautoscalingScalabletarget
metadata:
  name: my-scalabletarget
  namespace: aws-applicationautoscaling-system
spec:
  region: eu-west-1
  # ... ACK ScalableTarget spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsapplicationautoscalingscalabletargets.composition.krateo.io -n aws-applicationautoscaling-system
kubectl get scalabletargets.applicationautoscaling.services.k8s.aws -A
```
