# Krateo Blueprint — AWS Applicationautoscaling ScalingPolicy

> Generated by `tools/ackgen` from the ACK `ScalingPolicy` CRD (`applicationautoscaling.services.k8s.aws`).

Provisions an AWS Applicationautoscaling **ScalingPolicy** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
applicationautoscaling controller. The chart renders a native `applicationautoscaling.services.k8s.aws/v1alpha1` `ScalingPolicy`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsApplicationautoscalingScalingpolicy` Composition you create
becomes an AWS ScalingPolicy.

## Prerequisites

- **ACK applicationautoscaling controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-applicationautoscaling-controller \
    oci://public.ecr.aws/aws-controllers-k8s/applicationautoscaling-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ScalingPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-applicationautoscaling-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsApplicationautoscalingScalingpolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsApplicationautoscalingScalingpolicy` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsapplicationautoscalingscalingpolicies`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-applicationautoscaling-scalingpolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsApplicationautoscalingScalingpolicy
metadata:
  name: my-scalingpolicy
  namespace: aws-applicationautoscaling-system
spec:
  region: eu-west-1
  # ... ACK ScalingPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsapplicationautoscalingscalingpolicies.composition.krateo.io -n aws-applicationautoscaling-system
kubectl get scalingpolicys.applicationautoscaling.services.k8s.aws -A
```
