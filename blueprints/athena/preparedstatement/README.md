# Krateo Blueprint — AWS Athena PreparedStatement

> Generated by `tools/ackgen` from the ACK `PreparedStatement` CRD (`athena.services.k8s.aws`).

Provisions an AWS Athena **PreparedStatement** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
athena controller. The chart renders a native `athena.services.k8s.aws/v1alpha1` `PreparedStatement`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsAthenaPreparedstatement` Composition you create
becomes an AWS PreparedStatement.

## Prerequisites

- **ACK athena controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-athena-controller \
    oci://public.ecr.aws/aws-controllers-k8s/athena-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK PreparedStatement spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-athena-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsAthenaPreparedstatement type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsAthenaPreparedstatement` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsathenapreparedstatements`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-athena-preparedstatement`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsAthenaPreparedstatement
metadata:
  name: my-preparedstatement
  namespace: aws-athena-system
spec:
  region: eu-west-1
  # ... ACK PreparedStatement spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsathenapreparedstatements.composition.krateo.io -n aws-athena-system
kubectl get preparedstatements.athena.services.k8s.aws -A
```
