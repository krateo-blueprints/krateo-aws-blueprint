# Krateo Blueprint — AWS Backup BackupVault

> Generated by `tools/ackgen` from the ACK `BackupVault` CRD (`backup.services.k8s.aws`).

Provisions an AWS Backup **BackupVault** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
backup controller. The chart renders a native `backup.services.k8s.aws/v1alpha1` `BackupVault`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsBackupBackupvault` Composition you create
becomes an AWS BackupVault.

## Prerequisites

- **ACK backup controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-backup-controller \
    oci://public.ecr.aws/aws-controllers-k8s/backup-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK BackupVault spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-backup-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsBackupBackupvault type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsBackupBackupvault` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsbackupbackupvaults`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-backup-backupvault`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsBackupBackupvault
metadata:
  name: my-backupvault
  namespace: aws-backup-system
spec:
  region: eu-west-1
  # ... ACK BackupVault spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsbackupbackupvaults.composition.krateo.io -n aws-backup-system
kubectl get backupvaults.backup.services.k8s.aws -A
```
