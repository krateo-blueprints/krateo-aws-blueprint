# Krateo Blueprint — AWS Bedrock InferenceProfile

> Generated by `tools/ackgen` from the ACK `InferenceProfile` CRD (`bedrock.services.k8s.aws`).

Provisions an AWS Bedrock **InferenceProfile** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
bedrock controller. The chart renders a native `bedrock.services.k8s.aws/v1alpha1` `InferenceProfile`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsBedrockInferenceprofile` Composition you create
becomes an AWS InferenceProfile.

## Prerequisites

- **ACK bedrock controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-bedrock-controller \
    oci://public.ecr.aws/aws-controllers-k8s/bedrock-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK InferenceProfile spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-bedrock-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsBedrockInferenceprofile type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsBedrockInferenceprofile` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsbedrockinferenceprofiles`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-bedrock-inferenceprofile`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsBedrockInferenceprofile
metadata:
  name: my-inferenceprofile
  namespace: aws-bedrock-system
spec:
  region: eu-west-1
  # ... ACK InferenceProfile spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsbedrockinferenceprofiles.composition.krateo.io -n aws-bedrock-system
kubectl get inferenceprofiles.bedrock.services.k8s.aws -A
```
