# Krateo Blueprint — AWS Bedrockagentcorecontrol APIKeyCredentialProvider

> Generated by `tools/ackgen` from the ACK `APIKeyCredentialProvider` CRD (`bedrockagentcorecontrol.services.k8s.aws`).

Provisions an AWS Bedrockagentcorecontrol **APIKeyCredentialProvider** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
bedrockagentcorecontrol controller. The chart renders a native `bedrockagentcorecontrol.services.k8s.aws/v1alpha1` `APIKeyCredentialProvider`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsBedrockagentcorecontrolApikeycredentialprovider` Composition you create
becomes an AWS APIKeyCredentialProvider.

## Prerequisites

- **ACK bedrockagentcorecontrol controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-bedrockagentcorecontrol-controller \
    oci://public.ecr.aws/aws-controllers-k8s/bedrockagentcorecontrol-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK APIKeyCredentialProvider spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-bedrockagentcorecontrol-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-bedrockagentcorecontrol-apikeycredentialprovider.yaml"   # publishes the AwsBedrockagentcorecontrolApikeycredentialprovider type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsBedrockagentcorecontrolApikeycredentialprovider` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awsbedrockagentcorecontrolapikeycredentialproviders`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-bedrockagentcorecontrol-apikeycredentialprovider` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsBedrockagentcorecontrolApikeycredentialprovider
metadata:
  name: my-apikeycredentialprovider
  namespace: aws-bedrockagentcorecontrol-system
spec:
  region: eu-west-1
  # ... ACK APIKeyCredentialProvider spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsbedrockagentcorecontrolapikeycredentialproviders.composition.krateo.io -n aws-bedrockagentcorecontrol-system
kubectl get apikeycredentialproviders.bedrockagentcorecontrol.services.k8s.aws -A
```
