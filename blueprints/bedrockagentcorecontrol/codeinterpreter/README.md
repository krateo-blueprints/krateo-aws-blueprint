# Krateo Blueprint — AWS Bedrockagentcorecontrol CodeInterpreter

> Generated by `tools/ackgen` from the ACK `CodeInterpreter` CRD (`bedrockagentcorecontrol.services.k8s.aws`).

Provisions an AWS Bedrockagentcorecontrol **CodeInterpreter** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
bedrockagentcorecontrol controller. The chart renders a native `bedrockagentcorecontrol.services.k8s.aws/v1alpha1` `CodeInterpreter`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsBedrockagentcorecontrolCodeinterpreter` Composition you create
becomes an AWS CodeInterpreter.

## Prerequisites

- **ACK bedrockagentcorecontrol controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-bedrockagentcorecontrol-controller \
    oci://public.ecr.aws/aws-controllers-k8s/bedrockagentcorecontrol-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK CodeInterpreter spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-bedrockagentcorecontrol-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsBedrockagentcorecontrolCodeinterpreter type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsBedrockagentcorecontrolCodeinterpreter` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsbedrockagentcorecontrolcodeinterpreters`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-bedrockagentcorecontrol-codeinterpreter`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsBedrockagentcorecontrolCodeinterpreter
metadata:
  name: my-codeinterpreter
  namespace: aws-bedrockagentcorecontrol-system
spec:
  region: eu-west-1
  # ... ACK CodeInterpreter spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsbedrockagentcorecontrolcodeinterpreters.composition.krateo.io -n aws-bedrockagentcorecontrol-system
kubectl get codeinterpreters.bedrockagentcorecontrol.services.k8s.aws -A
```
