# Krateo Blueprint — AWS Bedrockagentcorecontrol WorkloadIdentity

> Generated by `tools/ackgen` from the ACK `WorkloadIdentity` CRD (`bedrockagentcorecontrol.services.k8s.aws`).

Provisions an AWS Bedrockagentcorecontrol **WorkloadIdentity** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
bedrockagentcorecontrol controller. The chart renders a native `bedrockagentcorecontrol.services.k8s.aws/v1alpha1` `WorkloadIdentity`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsBedrockagentcorecontrolWorkloadidentity` Composition you create
becomes an AWS WorkloadIdentity.

## Prerequisites

- **ACK bedrockagentcorecontrol controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-bedrockagentcorecontrol-controller \
    oci://public.ecr.aws/aws-controllers-k8s/bedrockagentcorecontrol-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK WorkloadIdentity spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-bedrockagentcorecontrol-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsBedrockagentcorecontrolWorkloadidentity type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsBedrockagentcorecontrolWorkloadidentity` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsbedrockagentcorecontrolworkloadidentities`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-bedrockagentcorecontrol-workloadidentity`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsBedrockagentcorecontrolWorkloadidentity
metadata:
  name: my-workloadidentity
  namespace: aws-bedrockagentcorecontrol-system
spec:
  region: eu-west-1
  # ... ACK WorkloadIdentity spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsbedrockagentcorecontrolworkloadidentities.composition.krateo.io -n aws-bedrockagentcorecontrol-system
kubectl get workloadidentitys.bedrockagentcorecontrol.services.k8s.aws -A
```
