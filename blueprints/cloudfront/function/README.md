# Krateo Blueprint — AWS Cloudfront Function

> Generated by `tools/ackgen` from the ACK `Function` CRD (`cloudfront.services.k8s.aws`).

Provisions an AWS Cloudfront **Function** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
cloudfront controller. The chart renders a native `cloudfront.services.k8s.aws/v1alpha1` `Function`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsCloudfrontFunction` Composition you create
becomes an AWS Function.

## Prerequisites

- **ACK cloudfront controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-cloudfront-controller \
    oci://public.ecr.aws/aws-controllers-k8s/cloudfront-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Function spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-cloudfront-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsCloudfrontFunction type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsCloudfrontFunction` Composition type (`composition.krateo.io/v0-1-1`,
plural `awscloudfrontfunctions`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-cloudfront-function`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsCloudfrontFunction
metadata:
  name: my-function
  namespace: aws-cloudfront-system
spec:
  region: eu-west-1
  # ... ACK Function spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awscloudfrontfunctions.composition.krateo.io -n aws-cloudfront-system
kubectl get functions.cloudfront.services.k8s.aws -A
```
