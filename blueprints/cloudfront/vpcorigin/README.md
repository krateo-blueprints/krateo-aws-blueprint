# Krateo Blueprint — AWS Cloudfront VPCOrigin

> Generated by `tools/ackgen` from the ACK `VPCOrigin` CRD (`cloudfront.services.k8s.aws`).

Provisions an AWS Cloudfront **VPCOrigin** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
cloudfront controller. The chart renders a native `cloudfront.services.k8s.aws/v1alpha1` `VPCOrigin`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsCloudfrontVpcorigin` Composition you create
becomes an AWS VPCOrigin.

## Prerequisites

- **ACK cloudfront controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-cloudfront-controller \
    oci://public.ecr.aws/aws-controllers-k8s/cloudfront-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK VPCOrigin spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-cloudfront-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsCloudfrontVpcorigin type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsCloudfrontVpcorigin` Composition type (`composition.krateo.io/v0-1-0`,
plural `awscloudfrontvpcorigins`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-cloudfront-vpcorigin`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsCloudfrontVpcorigin
metadata:
  name: my-vpcorigin
  namespace: aws-cloudfront-system
spec:
  region: eu-west-1
  # ... ACK VPCOrigin spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awscloudfrontvpcorigins.composition.krateo.io -n aws-cloudfront-system
kubectl get vpcorigins.cloudfront.services.k8s.aws -A
```
