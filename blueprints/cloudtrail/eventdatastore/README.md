# Krateo Blueprint — AWS Cloudtrail EventDataStore

> Generated by `tools/ackgen` from the ACK `EventDataStore` CRD (`cloudtrail.services.k8s.aws`).

Provisions an AWS Cloudtrail **EventDataStore** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
cloudtrail controller. The chart renders a native `cloudtrail.services.k8s.aws/v1alpha1` `EventDataStore`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsCloudtrailEventdatastore` Composition you create
becomes an AWS EventDataStore.

## Prerequisites

- **ACK cloudtrail controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-cloudtrail-controller \
    oci://public.ecr.aws/aws-controllers-k8s/cloudtrail-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK EventDataStore spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-cloudtrail-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsCloudtrailEventdatastore type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsCloudtrailEventdatastore` Composition type (`composition.krateo.io/v0-1-1`,
plural `awscloudtraileventdatastores`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-cloudtrail-eventdatastore`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsCloudtrailEventdatastore
metadata:
  name: my-eventdatastore
  namespace: aws-cloudtrail-system
spec:
  region: eu-west-1
  # ... ACK EventDataStore spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awscloudtraileventdatastores.composition.krateo.io -n aws-cloudtrail-system
kubectl get eventdatastores.cloudtrail.services.k8s.aws -A
```
