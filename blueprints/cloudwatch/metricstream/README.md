# Krateo Blueprint — AWS Cloudwatch MetricStream

> Generated by `tools/ackgen` from the ACK `MetricStream` CRD (`cloudwatch.services.k8s.aws`).

Provisions an AWS Cloudwatch **MetricStream** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
cloudwatch controller. The chart renders a native `cloudwatch.services.k8s.aws/v1alpha1` `MetricStream`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsCloudwatchMetricstream` Composition you create
becomes an AWS MetricStream.

## Prerequisites

- **ACK cloudwatch controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-cloudwatch-controller \
    oci://public.ecr.aws/aws-controllers-k8s/cloudwatch-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK MetricStream spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-cloudwatch-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsCloudwatchMetricstream type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsCloudwatchMetricstream` Composition type (`composition.krateo.io/v0-1-1`,
plural `awscloudwatchmetricstreams`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-cloudwatch-metricstream`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsCloudwatchMetricstream
metadata:
  name: my-metricstream
  namespace: aws-cloudwatch-system
spec:
  region: eu-west-1
  # ... ACK MetricStream spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awscloudwatchmetricstreams.composition.krateo.io -n aws-cloudwatch-system
kubectl get metricstreams.cloudwatch.services.k8s.aws -A
```
