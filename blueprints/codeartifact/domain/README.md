# Krateo Blueprint — AWS Codeartifact Domain

> Generated by `tools/ackgen` from the ACK `Domain` CRD (`codeartifact.services.k8s.aws`).

Provisions an AWS Codeartifact **Domain** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
codeartifact controller. The chart renders a native `codeartifact.services.k8s.aws/v1alpha1` `Domain`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsCodeartifactDomain` Composition you create
becomes an AWS Domain.

## Prerequisites

- **ACK codeartifact controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-codeartifact-controller \
    oci://public.ecr.aws/aws-controllers-k8s/codeartifact-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Domain spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-codeartifact-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsCodeartifactDomain type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsCodeartifactDomain` Composition type (`composition.krateo.io/v0-1-1`,
plural `awscodeartifactdomains`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-codeartifact-domain`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsCodeartifactDomain
metadata:
  name: my-domain
  namespace: aws-codeartifact-system
spec:
  region: eu-west-1
  # ... ACK Domain spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awscodeartifactdomains.composition.krateo.io -n aws-codeartifact-system
kubectl get domains.codeartifact.services.k8s.aws -A
```
