# Krateo Blueprint — AWS Documentdb DBSubnetGroup

> Generated by `tools/ackgen` from the ACK `DBSubnetGroup` CRD (`documentdb.services.k8s.aws`).

Provisions an AWS Documentdb **DBSubnetGroup** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
documentdb controller. The chart renders a native `documentdb.services.k8s.aws/v1alpha1` `DBSubnetGroup`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsDocumentdbDbsubnetgroup` Composition you create
becomes an AWS DBSubnetGroup.

## Prerequisites

- **ACK documentdb controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-documentdb-controller \
    oci://public.ecr.aws/aws-controllers-k8s/documentdb-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK DBSubnetGroup spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-documentdb-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsDocumentdbDbsubnetgroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsDocumentdbDbsubnetgroup` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsdocumentdbdbsubnetgroups`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-documentdb-dbsubnetgroup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsDocumentdbDbsubnetgroup
metadata:
  name: my-dbsubnetgroup
  namespace: aws-documentdb-system
spec:
  region: eu-west-1
  # ... ACK DBSubnetGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsdocumentdbdbsubnetgroups.composition.krateo.io -n aws-documentdb-system
kubectl get dbsubnetgroups.documentdb.services.k8s.aws -A
```
