# Krateo Blueprint — AWS Dsql Cluster

> Generated by `tools/ackgen` from the ACK `Cluster` CRD (`dsql.services.k8s.aws`).

Provisions an AWS Dsql **Cluster** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
dsql controller. The chart renders a native `dsql.services.k8s.aws/v1alpha1` `Cluster`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsDsqlCluster` Composition you create
becomes an AWS Cluster.

## Prerequisites

- **ACK dsql controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-dsql-controller \
    oci://public.ecr.aws/aws-controllers-k8s/dsql-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Cluster spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-dsql-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsDsqlCluster type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsDsqlCluster` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsdsqlclusters`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-dsql-cluster`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsDsqlCluster
metadata:
  name: my-cluster
  namespace: aws-dsql-system
spec:
  region: eu-west-1
  # ... ACK Cluster spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsdsqlclusters.composition.krateo.io -n aws-dsql-system
kubectl get clusters.dsql.services.k8s.aws -A
```
