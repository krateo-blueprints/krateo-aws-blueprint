# Krateo Blueprint — AWS Dynamodb Backup

> Generated by `tools/ackgen` from the ACK `Backup` CRD (`dynamodb.services.k8s.aws`).

Provisions an AWS Dynamodb **Backup** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
dynamodb controller. The chart renders a native `dynamodb.services.k8s.aws/v1alpha1` `Backup`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsDynamodbBackup` Composition you create
becomes an AWS Backup.

## Prerequisites

- **ACK dynamodb controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-dynamodb-controller \
    oci://public.ecr.aws/aws-controllers-k8s/dynamodb-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Backup spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-dynamodb-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-dynamodb-backup.yaml"   # publishes the AwsDynamodbBackup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsDynamodbBackup` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awsdynamodbbackups`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-dynamodb-backup` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsDynamodbBackup
metadata:
  name: my-backup
  namespace: aws-dynamodb-system
spec:
  region: eu-west-1
  # ... ACK Backup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsdynamodbbackups.composition.krateo.io -n aws-dynamodb-system
kubectl get backups.dynamodb.services.k8s.aws -A
```
