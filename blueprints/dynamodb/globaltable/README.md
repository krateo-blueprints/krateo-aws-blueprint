# Krateo Blueprint — AWS Dynamodb GlobalTable

> Generated by `tools/ackgen` from the ACK `GlobalTable` CRD (`dynamodb.services.k8s.aws`).

Provisions an AWS Dynamodb **GlobalTable** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
dynamodb controller. The chart renders a native `dynamodb.services.k8s.aws/v1alpha1` `GlobalTable`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsDynamodbGlobaltable` Composition you create
becomes an AWS GlobalTable.

## Prerequisites

- **ACK dynamodb controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-dynamodb-controller \
    oci://public.ecr.aws/aws-controllers-k8s/dynamodb-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK GlobalTable spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-dynamodb-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsDynamodbGlobaltable type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsDynamodbGlobaltable` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsdynamodbglobaltables`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-dynamodb-globaltable`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsDynamodbGlobaltable
metadata:
  name: my-globaltable
  namespace: aws-dynamodb-system
spec:
  region: eu-west-1
  # ... ACK GlobalTable spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsdynamodbglobaltables.composition.krateo.io -n aws-dynamodb-system
kubectl get globaltables.dynamodb.services.k8s.aws -A
```
