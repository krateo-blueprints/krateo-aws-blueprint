# Krateo Blueprint — AWS Dynamodb Table

> Generated by `tools/ackgen` from the ACK `Table` CRD (`dynamodb.services.k8s.aws`).

Provisions an AWS Dynamodb **Table** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
dynamodb controller. The chart renders a native `dynamodb.services.k8s.aws/v1alpha1` `Table`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsDynamodbTable` Composition you create
becomes an AWS Table.

## Prerequisites

- **ACK dynamodb controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-dynamodb-controller \
    oci://public.ecr.aws/aws-controllers-k8s/dynamodb-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Table spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-dynamodb-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsDynamodbTable type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsDynamodbTable` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsdynamodbtables`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-dynamodb-table`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsDynamodbTable
metadata:
  name: my-table
  namespace: aws-dynamodb-system
spec:
  region: eu-west-1
  # ... ACK Table spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsdynamodbtables.composition.krateo.io -n aws-dynamodb-system
kubectl get tables.dynamodb.services.k8s.aws -A
```
