# Krateo Blueprint — AWS Ec2 CapacityReservation

> Generated by `tools/ackgen` from the ACK `CapacityReservation` CRD (`ec2.services.k8s.aws`).

Provisions an AWS Ec2 **CapacityReservation** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ec2 controller. The chart renders a native `ec2.services.k8s.aws/v1alpha1` `CapacityReservation`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEc2Capacityreservation` Composition you create
becomes an AWS CapacityReservation.

## Prerequisites

- **ACK ec2 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ec2-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ec2-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK CapacityReservation spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-ec2-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-ec2-capacityreservation.yaml"   # publishes the AwsEc2Capacityreservation type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEc2Capacityreservation` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awsec2capacityreservations`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-ec2-capacityreservation` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsEc2Capacityreservation
metadata:
  name: my-capacityreservation
  namespace: aws-ec2-system
spec:
  region: eu-west-1
  # ... ACK CapacityReservation spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsec2capacityreservations.composition.krateo.io -n aws-ec2-system
kubectl get capacityreservations.ec2.services.k8s.aws -A
```
