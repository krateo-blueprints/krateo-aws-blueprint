# Krateo Blueprint — AWS Ec2 DHCPOptions

> Generated by `tools/ackgen` from the ACK `DHCPOptions` CRD (`ec2.services.k8s.aws`).

Provisions an AWS Ec2 **DHCPOptions** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ec2 controller. The chart renders a native `ec2.services.k8s.aws/v1alpha1` `DHCPOptions`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEc2Dhcpoptions` Composition you create
becomes an AWS DHCPOptions.

## Prerequisites

- **ACK ec2 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ec2-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ec2-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK DHCPOptions spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-ec2-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEc2Dhcpoptions type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEc2Dhcpoptions` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsec2dhcpoptions`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-ec2-dhcpoptions`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsEc2Dhcpoptions
metadata:
  name: my-dhcpoptions
  namespace: aws-ec2-system
spec:
  region: eu-west-1
  # ... ACK DHCPOptions spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsec2dhcpoptions.composition.krateo.io -n aws-ec2-system
kubectl get dhcpoptionss.ec2.services.k8s.aws -A
```
