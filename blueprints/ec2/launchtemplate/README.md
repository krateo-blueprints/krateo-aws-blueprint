# Krateo Blueprint — AWS Ec2 LaunchTemplate

> Generated by `tools/ackgen` from the ACK `LaunchTemplate` CRD (`ec2.services.k8s.aws`).

Provisions an AWS Ec2 **LaunchTemplate** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ec2 controller. The chart renders a native `ec2.services.k8s.aws/v1alpha1` `LaunchTemplate`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEc2Launchtemplate` Composition you create
becomes an AWS LaunchTemplate.

## Prerequisites

- **ACK ec2 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ec2-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ec2-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK LaunchTemplate spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-ec2-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEc2Launchtemplate type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEc2Launchtemplate` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsec2launchtemplates`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-ec2-launchtemplate`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsEc2Launchtemplate
metadata:
  name: my-launchtemplate
  namespace: aws-ec2-system
spec:
  region: eu-west-1
  # ... ACK LaunchTemplate spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsec2launchtemplates.composition.krateo.io -n aws-ec2-system
kubectl get launchtemplates.ec2.services.k8s.aws -A
```
