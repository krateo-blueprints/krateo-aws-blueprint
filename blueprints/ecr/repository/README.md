# Krateo Blueprint — AWS Ecr Repository

> Generated by `tools/ackgen` from the ACK `Repository` CRD (`ecr.services.k8s.aws`).

Provisions an AWS Ecr **Repository** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ecr controller. The chart renders a native `ecr.services.k8s.aws/v1alpha1` `Repository`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEcrRepository` Composition you create
becomes an AWS Repository.

## Prerequisites

- **ACK ecr controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ecr-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ecr-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Repository spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-ecr-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEcrRepository type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEcrRepository` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsecrrepositories`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-ecr-repository`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsEcrRepository
metadata:
  name: my-repository
  namespace: aws-ecr-system
spec:
  region: eu-west-1
  # ... ACK Repository spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsecrrepositories.composition.krateo.io -n aws-ecr-system
kubectl get repositorys.ecr.services.k8s.aws -A
```
