# Krateo Blueprint — AWS Ecrpublic Repository

> Generated by `tools/ackgen` from the ACK `Repository` CRD (`ecrpublic.services.k8s.aws`).

Provisions an AWS Ecrpublic **Repository** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ecrpublic controller. The chart renders a native `ecrpublic.services.k8s.aws/v1alpha1` `Repository`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEcrpublicRepository` Composition you create
becomes an AWS Repository.

## Prerequisites

- **ACK ecrpublic controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ecrpublic-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ecrpublic-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Repository spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-ecrpublic-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEcrpublicRepository type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEcrpublicRepository` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsecrpublicrepositories`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-ecrpublic-repository`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsEcrpublicRepository
metadata:
  name: my-repository
  namespace: aws-ecrpublic-system
spec:
  region: eu-west-1
  # ... ACK Repository spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsecrpublicrepositories.composition.krateo.io -n aws-ecrpublic-system
kubectl get repositorys.ecrpublic.services.k8s.aws -A
```
