# Krateo Blueprint — AWS Efs AccessPoint

> Generated by `tools/ackgen` from the ACK `AccessPoint` CRD (`efs.services.k8s.aws`).

Provisions an AWS Efs **AccessPoint** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
efs controller. The chart renders a native `efs.services.k8s.aws/v1alpha1` `AccessPoint`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEfsAccesspoint` Composition you create
becomes an AWS AccessPoint.

## Prerequisites

- **ACK efs controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-efs-controller \
    oci://public.ecr.aws/aws-controllers-k8s/efs-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK AccessPoint spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-efs-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEfsAccesspoint type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEfsAccesspoint` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsefsaccesspoints`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-efs-accesspoint`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsEfsAccesspoint
metadata:
  name: my-accesspoint
  namespace: aws-efs-system
spec:
  region: eu-west-1
  # ... ACK AccessPoint spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsefsaccesspoints.composition.krateo.io -n aws-efs-system
kubectl get accesspoints.efs.services.k8s.aws -A
```
