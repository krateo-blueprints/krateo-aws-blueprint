# Krateo Blueprint — AWS Eks Capability

> Generated by `tools/ackgen` from the ACK `Capability` CRD (`eks.services.k8s.aws`).

Provisions an AWS Eks **Capability** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
eks controller. The chart renders a native `eks.services.k8s.aws/v1alpha1` `Capability`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEksCapability` Composition you create
becomes an AWS Capability.

## Prerequisites

- **ACK eks controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-eks-controller \
    oci://public.ecr.aws/aws-controllers-k8s/eks-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Capability spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-eks-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEksCapability type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEksCapability` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsekscapabilities`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-eks-capability`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsEksCapability
metadata:
  name: my-capability
  namespace: aws-eks-system
spec:
  region: eu-west-1
  # ... ACK Capability spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsekscapabilities.composition.krateo.io -n aws-eks-system
kubectl get capabilitys.eks.services.k8s.aws -A
```
