# Krateo Blueprint — AWS Eks FargateProfile

> Generated by `tools/ackgen` from the ACK `FargateProfile` CRD (`eks.services.k8s.aws`).

Provisions an AWS Eks **FargateProfile** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
eks controller. The chart renders a native `eks.services.k8s.aws/v1alpha1` `FargateProfile`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEksFargateprofile` Composition you create
becomes an AWS FargateProfile.

## Prerequisites

- **ACK eks controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-eks-controller \
    oci://public.ecr.aws/aws-controllers-k8s/eks-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK FargateProfile spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-eks-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEksFargateprofile type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEksFargateprofile` Composition type (`composition.krateo.io/v0-1-1`,
plural `awseksfargateprofiles`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-eks-fargateprofile`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsEksFargateprofile
metadata:
  name: my-fargateprofile
  namespace: aws-eks-system
spec:
  region: eu-west-1
  # ... ACK FargateProfile spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awseksfargateprofiles.composition.krateo.io -n aws-eks-system
kubectl get fargateprofiles.eks.services.k8s.aws -A
```
