# Krateo Blueprint — AWS Elasticache CacheSubnetGroup

> Generated by `tools/ackgen` from the ACK `CacheSubnetGroup` CRD (`elasticache.services.k8s.aws`).

Provisions an AWS Elasticache **CacheSubnetGroup** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
elasticache controller. The chart renders a native `elasticache.services.k8s.aws/v1alpha1` `CacheSubnetGroup`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsElasticacheCachesubnetgroup` Composition you create
becomes an AWS CacheSubnetGroup.

## Prerequisites

- **ACK elasticache controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-elasticache-controller \
    oci://public.ecr.aws/aws-controllers-k8s/elasticache-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK CacheSubnetGroup spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-elasticache-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsElasticacheCachesubnetgroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsElasticacheCachesubnetgroup` Composition type (`composition.krateo.io/v0-1-0`,
plural `awselasticachecachesubnetgroups`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-elasticache-cachesubnetgroup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsElasticacheCachesubnetgroup
metadata:
  name: my-cachesubnetgroup
  namespace: aws-elasticache-system
spec:
  region: eu-west-1
  # ... ACK CacheSubnetGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awselasticachecachesubnetgroups.composition.krateo.io -n aws-elasticache-system
kubectl get cachesubnetgroups.elasticache.services.k8s.aws -A
```
