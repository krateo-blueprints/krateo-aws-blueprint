# Krateo Blueprint — AWS Elasticache ServerlessCacheSnapshot

> Generated by `tools/ackgen` from the ACK `ServerlessCacheSnapshot` CRD (`elasticache.services.k8s.aws`).

Provisions an AWS Elasticache **ServerlessCacheSnapshot** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
elasticache controller. The chart renders a native `elasticache.services.k8s.aws/v1alpha1` `ServerlessCacheSnapshot`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsElasticacheServerlesscachesnapshot` Composition you create
becomes an AWS ServerlessCacheSnapshot.

## Prerequisites

- **ACK elasticache controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-elasticache-controller \
    oci://public.ecr.aws/aws-controllers-k8s/elasticache-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ServerlessCacheSnapshot spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-elasticache-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsElasticacheServerlesscachesnapshot type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsElasticacheServerlesscachesnapshot` Composition type (`composition.krateo.io/v0-1-1`,
plural `awselasticacheserverlesscachesnapshots`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-elasticache-serverlesscachesnapshot`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsElasticacheServerlesscachesnapshot
metadata:
  name: my-serverlesscachesnapshot
  namespace: aws-elasticache-system
spec:
  region: eu-west-1
  # ... ACK ServerlessCacheSnapshot spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awselasticacheserverlesscachesnapshots.composition.krateo.io -n aws-elasticache-system
kubectl get serverlesscachesnapshots.elasticache.services.k8s.aws -A
```
