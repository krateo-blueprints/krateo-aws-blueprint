# Krateo Blueprint — AWS Elasticache Snapshot

> Generated by `tools/ackgen` from the ACK `Snapshot` CRD (`elasticache.services.k8s.aws`).

Provisions an AWS Elasticache **Snapshot** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
elasticache controller. The chart renders a native `elasticache.services.k8s.aws/v1alpha1` `Snapshot`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsElasticacheSnapshot` Composition you create
becomes an AWS Snapshot.

## Prerequisites

- **ACK elasticache controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-elasticache-controller \
    oci://public.ecr.aws/aws-controllers-k8s/elasticache-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Snapshot spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-elasticache-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsElasticacheSnapshot type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsElasticacheSnapshot` Composition type (`composition.krateo.io/v0-1-1`,
plural `awselasticachesnapshots`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-elasticache-snapshot`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsElasticacheSnapshot
metadata:
  name: my-snapshot
  namespace: aws-elasticache-system
spec:
  region: eu-west-1
  # ... ACK Snapshot spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awselasticachesnapshots.composition.krateo.io -n aws-elasticache-system
kubectl get snapshots.elasticache.services.k8s.aws -A
```
