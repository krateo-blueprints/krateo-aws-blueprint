# Krateo Blueprint — AWS Elbv2 Listener

> Generated by `tools/ackgen` from the ACK `Listener` CRD (`elbv2.services.k8s.aws`).

Provisions an AWS Elbv2 **Listener** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
elbv2 controller. The chart renders a native `elbv2.services.k8s.aws/v1alpha1` `Listener`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsElbv2Listener` Composition you create
becomes an AWS Listener.

## Prerequisites

- **ACK elbv2 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-elbv2-controller \
    oci://public.ecr.aws/aws-controllers-k8s/elbv2-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Listener spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-elbv2-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-elbv2-listener.yaml"   # publishes the AwsElbv2Listener type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsElbv2Listener` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awselbv2listeners`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-elbv2-listener` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsElbv2Listener
metadata:
  name: my-listener
  namespace: aws-elbv2-system
spec:
  region: eu-west-1
  # ... ACK Listener spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awselbv2listeners.composition.krateo.io -n aws-elbv2-system
kubectl get listeners.elbv2.services.k8s.aws -A
```
