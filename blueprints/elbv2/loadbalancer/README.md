# Krateo Blueprint — AWS Elbv2 LoadBalancer

> Generated by `tools/ackgen` from the ACK `LoadBalancer` CRD (`elbv2.services.k8s.aws`).

Provisions an AWS Elbv2 **LoadBalancer** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
elbv2 controller. The chart renders a native `elbv2.services.k8s.aws/v1alpha1` `LoadBalancer`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsElbv2Loadbalancer` Composition you create
becomes an AWS LoadBalancer.

## Prerequisites

- **ACK elbv2 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-elbv2-controller \
    oci://public.ecr.aws/aws-controllers-k8s/elbv2-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK LoadBalancer spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-elbv2-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsElbv2Loadbalancer type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsElbv2Loadbalancer` Composition type (`composition.krateo.io/v0-1-0`,
plural `awselbv2loadbalancers`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-elbv2-loadbalancer`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsElbv2Loadbalancer
metadata:
  name: my-loadbalancer
  namespace: aws-elbv2-system
spec:
  region: eu-west-1
  # ... ACK LoadBalancer spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awselbv2loadbalancers.composition.krateo.io -n aws-elbv2-system
kubectl get loadbalancers.elbv2.services.k8s.aws -A
```
