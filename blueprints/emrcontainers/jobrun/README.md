# Krateo Blueprint — AWS Emrcontainers JobRun

> Generated by `tools/ackgen` from the ACK `JobRun` CRD (`emrcontainers.services.k8s.aws`).

Provisions an AWS Emrcontainers **JobRun** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
emrcontainers controller. The chart renders a native `emrcontainers.services.k8s.aws/v1alpha1` `JobRun`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEmrcontainersJobrun` Composition you create
becomes an AWS JobRun.

## Prerequisites

- **ACK emrcontainers controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-emrcontainers-controller \
    oci://public.ecr.aws/aws-controllers-k8s/emrcontainers-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK JobRun spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-emrcontainers-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEmrcontainersJobrun type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEmrcontainersJobrun` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsemrcontainersjobruns`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-emrcontainers-jobrun`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsEmrcontainersJobrun
metadata:
  name: my-jobrun
  namespace: aws-emrcontainers-system
spec:
  region: eu-west-1
  # ... ACK JobRun spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsemrcontainersjobruns.composition.krateo.io -n aws-emrcontainers-system
kubectl get jobruns.emrcontainers.services.k8s.aws -A
```
