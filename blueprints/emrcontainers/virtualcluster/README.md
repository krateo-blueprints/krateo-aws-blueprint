# Krateo Blueprint — AWS Emrcontainers VirtualCluster

> Generated by `tools/ackgen` from the ACK `VirtualCluster` CRD (`emrcontainers.services.k8s.aws`).

Provisions an AWS Emrcontainers **VirtualCluster** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
emrcontainers controller. The chart renders a native `emrcontainers.services.k8s.aws/v1alpha1` `VirtualCluster`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEmrcontainersVirtualcluster` Composition you create
becomes an AWS VirtualCluster.

## Prerequisites

- **ACK emrcontainers controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-emrcontainers-controller \
    oci://public.ecr.aws/aws-controllers-k8s/emrcontainers-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK VirtualCluster spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-emrcontainers-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEmrcontainersVirtualcluster type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEmrcontainersVirtualcluster` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsemrcontainersvirtualclusters`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-emrcontainers-virtualcluster`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsEmrcontainersVirtualcluster
metadata:
  name: my-virtualcluster
  namespace: aws-emrcontainers-system
spec:
  region: eu-west-1
  # ... ACK VirtualCluster spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsemrcontainersvirtualclusters.composition.krateo.io -n aws-emrcontainers-system
kubectl get virtualclusters.emrcontainers.services.k8s.aws -A
```
