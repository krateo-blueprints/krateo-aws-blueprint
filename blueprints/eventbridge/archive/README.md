# Krateo Blueprint — AWS Eventbridge Archive

> Generated by `tools/ackgen` from the ACK `Archive` CRD (`eventbridge.services.k8s.aws`).

Provisions an AWS Eventbridge **Archive** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
eventbridge controller. The chart renders a native `eventbridge.services.k8s.aws/v1alpha1` `Archive`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEventbridgeArchive` Composition you create
becomes an AWS Archive.

## Prerequisites

- **ACK eventbridge controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-eventbridge-controller \
    oci://public.ecr.aws/aws-controllers-k8s/eventbridge-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Archive spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-eventbridge-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-eventbridge-archive.yaml"   # publishes the AwsEventbridgeArchive type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEventbridgeArchive` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awseventbridgearchives`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-eventbridge-archive` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsEventbridgeArchive
metadata:
  name: my-archive
  namespace: aws-eventbridge-system
spec:
  region: eu-west-1
  # ... ACK Archive spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awseventbridgearchives.composition.krateo.io -n aws-eventbridge-system
kubectl get archives.eventbridge.services.k8s.aws -A
```
