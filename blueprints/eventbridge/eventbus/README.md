# Krateo Blueprint — AWS Eventbridge EventBus

> Generated by `tools/ackgen` from the ACK `EventBus` CRD (`eventbridge.services.k8s.aws`).

Provisions an AWS Eventbridge **EventBus** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
eventbridge controller. The chart renders a native `eventbridge.services.k8s.aws/v1alpha1` `EventBus`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEventbridgeEventbus` Composition you create
becomes an AWS EventBus.

## Prerequisites

- **ACK eventbridge controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-eventbridge-controller \
    oci://public.ecr.aws/aws-controllers-k8s/eventbridge-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK EventBus spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-eventbridge-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEventbridgeEventbus type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEventbridgeEventbus` Composition type (`composition.krateo.io/v0-1-0`,
plural `awseventbridgeeventbuses`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-eventbridge-eventbus`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsEventbridgeEventbus
metadata:
  name: my-eventbus
  namespace: aws-eventbridge-system
spec:
  region: eu-west-1
  # ... ACK EventBus spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awseventbridgeeventbuses.composition.krateo.io -n aws-eventbridge-system
kubectl get eventbuss.eventbridge.services.k8s.aws -A
```
