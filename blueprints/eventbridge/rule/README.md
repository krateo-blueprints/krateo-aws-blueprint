# Krateo Blueprint — AWS Eventbridge Rule

> Generated by `tools/ackgen` from the ACK `Rule` CRD (`eventbridge.services.k8s.aws`).

Provisions an AWS Eventbridge **Rule** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
eventbridge controller. The chart renders a native `eventbridge.services.k8s.aws/v1alpha1` `Rule`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsEventbridgeRule` Composition you create
becomes an AWS Rule.

## Prerequisites

- **ACK eventbridge controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-eventbridge-controller \
    oci://public.ecr.aws/aws-controllers-k8s/eventbridge-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Rule spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-eventbridge-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsEventbridgeRule type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsEventbridgeRule` Composition type (`composition.krateo.io/v0-1-1`,
plural `awseventbridgerules`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-eventbridge-rule`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsEventbridgeRule
metadata:
  name: my-rule
  namespace: aws-eventbridge-system
spec:
  region: eu-west-1
  # ... ACK Rule spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awseventbridgerules.composition.krateo.io -n aws-eventbridge-system
kubectl get rules.eventbridge.services.k8s.aws -A
```
