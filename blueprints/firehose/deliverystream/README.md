# Krateo Blueprint — AWS Firehose DeliveryStream

> Generated by `tools/ackgen` from the ACK `DeliveryStream` CRD (`firehose.services.k8s.aws`).

Provisions an AWS Firehose **DeliveryStream** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
firehose controller. The chart renders a native `firehose.services.k8s.aws/v1alpha1` `DeliveryStream`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsFirehoseDeliverystream` Composition you create
becomes an AWS DeliveryStream.

## Prerequisites

- **ACK firehose controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-firehose-controller \
    oci://public.ecr.aws/aws-controllers-k8s/firehose-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK DeliveryStream spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-firehose-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsFirehoseDeliverystream type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsFirehoseDeliverystream` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsfirehosedeliverystreams`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-firehose-deliverystream`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsFirehoseDeliverystream
metadata:
  name: my-deliverystream
  namespace: aws-firehose-system
spec:
  region: eu-west-1
  # ... ACK DeliveryStream spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsfirehosedeliverystreams.composition.krateo.io -n aws-firehose-system
kubectl get deliverystreams.firehose.services.k8s.aws -A
```
