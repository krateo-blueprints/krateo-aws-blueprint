# Krateo Blueprint — AWS Glue Job

> Generated by `tools/ackgen` from the ACK `Job` CRD (`glue.services.k8s.aws`).

Provisions an AWS Glue **Job** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
glue controller. The chart renders a native `glue.services.k8s.aws/v1alpha1` `Job`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsGlueJob` Composition you create
becomes an AWS Job.

## Prerequisites

- **ACK glue controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-glue-controller \
    oci://public.ecr.aws/aws-controllers-k8s/glue-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Job spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-glue-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsGlueJob type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsGlueJob` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsgluejobs`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-glue-job`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsGlueJob
metadata:
  name: my-job
  namespace: aws-glue-system
spec:
  region: eu-west-1
  # ... ACK Job spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsgluejobs.composition.krateo.io -n aws-glue-system
kubectl get jobs.glue.services.k8s.aws -A
```
