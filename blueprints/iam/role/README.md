# Krateo Blueprint — AWS Iam Role

> Generated by `tools/ackgen` from the ACK `Role` CRD (`iam.services.k8s.aws`).

Provisions an AWS Iam **Role** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
iam controller. The chart renders a native `iam.services.k8s.aws/v1alpha1` `Role`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsIamRole` Composition you create
becomes an AWS Role.

## Prerequisites

- **ACK iam controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-iam-controller \
    oci://public.ecr.aws/aws-controllers-k8s/iam-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Role spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-iam-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsIamRole type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsIamRole` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsiamroles`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-iam-role`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsIamRole
metadata:
  name: my-role
  namespace: aws-iam-system
spec:
  region: eu-west-1
  # ... ACK Role spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsiamroles.composition.krateo.io -n aws-iam-system
kubectl get roles.iam.services.k8s.aws -A
```
