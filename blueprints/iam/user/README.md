# Krateo Blueprint — AWS Iam User

> Generated by `tools/ackgen` from the ACK `User` CRD (`iam.services.k8s.aws`).

Provisions an AWS Iam **User** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
iam controller. The chart renders a native `iam.services.k8s.aws/v1alpha1` `User`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsIamUser` Composition you create
becomes an AWS User.

## Prerequisites

- **ACK iam controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-iam-controller \
    oci://public.ecr.aws/aws-controllers-k8s/iam-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK User spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-iam-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsIamUser type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsIamUser` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsiamusers`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-iam-user`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsIamUser
metadata:
  name: my-user
  namespace: aws-iam-system
spec:
  region: eu-west-1
  # ... ACK User spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsiamusers.composition.krateo.io -n aws-iam-system
kubectl get users.iam.services.k8s.aws -A
```
