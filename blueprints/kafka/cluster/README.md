# Krateo Blueprint — AWS Kafka Cluster

> Generated by `tools/ackgen` from the ACK `Cluster` CRD (`kafka.services.k8s.aws`).

Provisions an AWS Kafka **Cluster** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
kafka controller. The chart renders a native `kafka.services.k8s.aws/v1alpha1` `Cluster`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsKafkaCluster` Composition you create
becomes an AWS Cluster.

## Prerequisites

- **ACK kafka controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-kafka-controller \
    oci://public.ecr.aws/aws-controllers-k8s/kafka-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Cluster spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-kafka-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsKafkaCluster type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsKafkaCluster` Composition type (`composition.krateo.io/v0-1-1`,
plural `awskafkaclusters`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-kafka-cluster`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsKafkaCluster
metadata:
  name: my-cluster
  namespace: aws-kafka-system
spec:
  region: eu-west-1
  # ... ACK Cluster spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awskafkaclusters.composition.krateo.io -n aws-kafka-system
kubectl get clusters.kafka.services.k8s.aws -A
```
