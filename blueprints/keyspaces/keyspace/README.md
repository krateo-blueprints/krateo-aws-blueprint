# Krateo Blueprint — AWS Keyspaces Keyspace

> Generated by `tools/ackgen` from the ACK `Keyspace` CRD (`keyspaces.services.k8s.aws`).

Provisions an AWS Keyspaces **Keyspace** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
keyspaces controller. The chart renders a native `keyspaces.services.k8s.aws/v1alpha1` `Keyspace`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsKeyspacesKeyspace` Composition you create
becomes an AWS Keyspace.

## Prerequisites

- **ACK keyspaces controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-keyspaces-controller \
    oci://public.ecr.aws/aws-controllers-k8s/keyspaces-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Keyspace spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-keyspaces-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsKeyspacesKeyspace type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsKeyspacesKeyspace` Composition type (`composition.krateo.io/v0-1-1`,
plural `awskeyspaceskeyspaces`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-keyspaces-keyspace`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsKeyspacesKeyspace
metadata:
  name: my-keyspace
  namespace: aws-keyspaces-system
spec:
  region: eu-west-1
  # ... ACK Keyspace spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awskeyspaceskeyspaces.composition.krateo.io -n aws-keyspaces-system
kubectl get keyspaces.keyspaces.services.k8s.aws -A
```
