# Krateo Blueprint — AWS Kinesis Stream

> Generated by `tools/ackgen` from the ACK `Stream` CRD (`kinesis.services.k8s.aws`).

Provisions an AWS Kinesis **Stream** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
kinesis controller. The chart renders a native `kinesis.services.k8s.aws/v1alpha1` `Stream`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsKinesisStream` Composition you create
becomes an AWS Stream.

## Prerequisites

- **ACK kinesis controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-kinesis-controller \
    oci://public.ecr.aws/aws-controllers-k8s/kinesis-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Stream spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-kinesis-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsKinesisStream type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsKinesisStream` Composition type (`composition.krateo.io/v0-1-1`,
plural `awskinesisstreams`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-kinesis-stream`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsKinesisStream
metadata:
  name: my-stream
  namespace: aws-kinesis-system
spec:
  region: eu-west-1
  # ... ACK Stream spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awskinesisstreams.composition.krateo.io -n aws-kinesis-system
kubectl get streams.kinesis.services.k8s.aws -A
```
