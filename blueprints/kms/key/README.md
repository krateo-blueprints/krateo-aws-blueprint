# Krateo Blueprint — AWS Kms Key

> Generated by `tools/ackgen` from the ACK `Key` CRD (`kms.services.k8s.aws`).

Provisions an AWS Kms **Key** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
kms controller. The chart renders a native `kms.services.k8s.aws/v1alpha1` `Key`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsKmsKey` Composition you create
becomes an AWS Key.

## Prerequisites

- **ACK kms controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-kms-controller \
    oci://public.ecr.aws/aws-controllers-k8s/kms-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Key spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-kms-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsKmsKey type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsKmsKey` Composition type (`composition.krateo.io/v0-1-1`,
plural `awskmskeys`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-kms-key`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsKmsKey
metadata:
  name: my-key
  namespace: aws-kms-system
spec:
  region: eu-west-1
  # ... ACK Key spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awskmskeys.composition.krateo.io -n aws-kms-system
kubectl get keys.kms.services.k8s.aws -A
```
