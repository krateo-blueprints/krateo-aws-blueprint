# Krateo Blueprint — AWS Lambda CodeSigningConfig

> Generated by `tools/ackgen` from the ACK `CodeSigningConfig` CRD (`lambda.services.k8s.aws`).

Provisions an AWS Lambda **CodeSigningConfig** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
lambda controller. The chart renders a native `lambda.services.k8s.aws/v1alpha1` `CodeSigningConfig`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsLambdaCodesigningconfig` Composition you create
becomes an AWS CodeSigningConfig.

## Prerequisites

- **ACK lambda controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-lambda-controller \
    oci://public.ecr.aws/aws-controllers-k8s/lambda-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK CodeSigningConfig spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-lambda-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsLambdaCodesigningconfig type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsLambdaCodesigningconfig` Composition type (`composition.krateo.io/v0-1-1`,
plural `awslambdacodesigningconfigs`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-lambda-codesigningconfig`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsLambdaCodesigningconfig
metadata:
  name: my-codesigningconfig
  namespace: aws-lambda-system
spec:
  region: eu-west-1
  # ... ACK CodeSigningConfig spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awslambdacodesigningconfigs.composition.krateo.io -n aws-lambda-system
kubectl get codesigningconfigs.lambda.services.k8s.aws -A
```
