# Krateo Blueprint — AWS Lambda FunctionURLConfig

> Generated by `tools/ackgen` from the ACK `FunctionURLConfig` CRD (`lambda.services.k8s.aws`).

Provisions an AWS Lambda **FunctionURLConfig** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
lambda controller. The chart renders a native `lambda.services.k8s.aws/v1alpha1` `FunctionURLConfig`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsLambdaFunctionurlconfig` Composition you create
becomes an AWS FunctionURLConfig.

## Prerequisites

- **ACK lambda controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-lambda-controller \
    oci://public.ecr.aws/aws-controllers-k8s/lambda-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK FunctionURLConfig spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-lambda-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsLambdaFunctionurlconfig type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsLambdaFunctionurlconfig` Composition type (`composition.krateo.io/v0-1-1`,
plural `awslambdafunctionurlconfigs`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-lambda-functionurlconfig`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsLambdaFunctionurlconfig
metadata:
  name: my-functionurlconfig
  namespace: aws-lambda-system
spec:
  region: eu-west-1
  # ... ACK FunctionURLConfig spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awslambdafunctionurlconfigs.composition.krateo.io -n aws-lambda-system
kubectl get functionurlconfigs.lambda.services.k8s.aws -A
```
