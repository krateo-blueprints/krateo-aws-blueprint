# Krateo Blueprint — AWS Lambda Version

> Generated by `tools/ackgen` from the ACK `Version` CRD (`lambda.services.k8s.aws`).

Provisions an AWS Lambda **Version** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
lambda controller. The chart renders a native `lambda.services.k8s.aws/v1alpha1` `Version`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsLambdaVersion` Composition you create
becomes an AWS Version.

## Prerequisites

- **ACK lambda controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-lambda-controller \
    oci://public.ecr.aws/aws-controllers-k8s/lambda-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Version spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-lambda-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsLambdaVersion type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsLambdaVersion` Composition type (`composition.krateo.io/v0-1-0`,
plural `awslambdaversions`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-lambda-version`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsLambdaVersion
metadata:
  name: my-version
  namespace: aws-lambda-system
spec:
  region: eu-west-1
  # ... ACK Version spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awslambdaversions.composition.krateo.io -n aws-lambda-system
kubectl get versions.lambda.services.k8s.aws -A
```
