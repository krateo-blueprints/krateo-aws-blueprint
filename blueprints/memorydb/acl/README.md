# Krateo Blueprint — AWS Memorydb ACL

> Generated by `tools/ackgen` from the ACK `ACL` CRD (`memorydb.services.k8s.aws`).

Provisions an AWS Memorydb **ACL** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
memorydb controller. The chart renders a native `memorydb.services.k8s.aws/v1alpha1` `ACL`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsMemorydbACL` Composition you create
becomes an AWS ACL.

## Prerequisites

- **ACK memorydb controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-memorydb-controller \
    oci://public.ecr.aws/aws-controllers-k8s/memorydb-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ACL spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-memorydb-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsMemorydbACL type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsMemorydbACL` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsmemorydbacls`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-memorydb-acl`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsMemorydbACL
metadata:
  name: my-acl
  namespace: aws-memorydb-system
spec:
  region: eu-west-1
  # ... ACK ACL spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsmemorydbacls.composition.krateo.io -n aws-memorydb-system
kubectl get acls.memorydb.services.k8s.aws -A
```
