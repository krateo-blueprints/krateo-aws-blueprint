# Krateo Blueprint — AWS Memorydb ParameterGroup

> Generated by `tools/ackgen` from the ACK `ParameterGroup` CRD (`memorydb.services.k8s.aws`).

Provisions an AWS Memorydb **ParameterGroup** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
memorydb controller. The chart renders a native `memorydb.services.k8s.aws/v1alpha1` `ParameterGroup`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsMemorydbParametergroup` Composition you create
becomes an AWS ParameterGroup.

## Prerequisites

- **ACK memorydb controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-memorydb-controller \
    oci://public.ecr.aws/aws-controllers-k8s/memorydb-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ParameterGroup spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-memorydb-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsMemorydbParametergroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsMemorydbParametergroup` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsmemorydbparametergroups`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-memorydb-parametergroup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsMemorydbParametergroup
metadata:
  name: my-parametergroup
  namespace: aws-memorydb-system
spec:
  region: eu-west-1
  # ... ACK ParameterGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsmemorydbparametergroups.composition.krateo.io -n aws-memorydb-system
kubectl get parametergroups.memorydb.services.k8s.aws -A
```
