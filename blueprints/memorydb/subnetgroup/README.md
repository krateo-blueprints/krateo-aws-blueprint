# Krateo Blueprint — AWS Memorydb SubnetGroup

> Generated by `tools/ackgen` from the ACK `SubnetGroup` CRD (`memorydb.services.k8s.aws`).

Provisions an AWS Memorydb **SubnetGroup** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
memorydb controller. The chart renders a native `memorydb.services.k8s.aws/v1alpha1` `SubnetGroup`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsMemorydbSubnetgroup` Composition you create
becomes an AWS SubnetGroup.

## Prerequisites

- **ACK memorydb controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-memorydb-controller \
    oci://public.ecr.aws/aws-controllers-k8s/memorydb-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK SubnetGroup spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-memorydb-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-memorydb-subnetgroup.yaml"   # publishes the AwsMemorydbSubnetgroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsMemorydbSubnetgroup` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awsmemorydbsubnetgroups`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-memorydb-subnetgroup` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsMemorydbSubnetgroup
metadata:
  name: my-subnetgroup
  namespace: aws-memorydb-system
spec:
  region: eu-west-1
  # ... ACK SubnetGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsmemorydbsubnetgroups.composition.krateo.io -n aws-memorydb-system
kubectl get subnetgroups.memorydb.services.k8s.aws -A
```
