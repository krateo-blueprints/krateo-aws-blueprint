# Krateo Blueprint — AWS Memorydb User

> Generated by `tools/ackgen` from the ACK `User` CRD (`memorydb.services.k8s.aws`).

Provisions an AWS Memorydb **User** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
memorydb controller. The chart renders a native `memorydb.services.k8s.aws/v1alpha1` `User`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsMemorydbUser` Composition you create
becomes an AWS User.

## Prerequisites

- **ACK memorydb controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-memorydb-controller \
    oci://public.ecr.aws/aws-controllers-k8s/memorydb-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK User spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-memorydb-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-memorydb-user.yaml"   # publishes the AwsMemorydbUser type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsMemorydbUser` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awsmemorydbusers`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-memorydb-user` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsMemorydbUser
metadata:
  name: my-user
  namespace: aws-memorydb-system
spec:
  region: eu-west-1
  # ... ACK User spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsmemorydbusers.composition.krateo.io -n aws-memorydb-system
kubectl get users.memorydb.services.k8s.aws -A
```
