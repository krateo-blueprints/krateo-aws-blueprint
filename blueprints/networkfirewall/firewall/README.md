# Krateo Blueprint — AWS Networkfirewall Firewall

> Generated by `tools/ackgen` from the ACK `Firewall` CRD (`networkfirewall.services.k8s.aws`).

Provisions an AWS Networkfirewall **Firewall** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
networkfirewall controller. The chart renders a native `networkfirewall.services.k8s.aws/v1alpha1` `Firewall`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsNetworkfirewallFirewall` Composition you create
becomes an AWS Firewall.

## Prerequisites

- **ACK networkfirewall controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-networkfirewall-controller \
    oci://public.ecr.aws/aws-controllers-k8s/networkfirewall-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Firewall spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-networkfirewall-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsNetworkfirewallFirewall type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsNetworkfirewallFirewall` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsnetworkfirewallfirewalls`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-networkfirewall-firewall`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsNetworkfirewallFirewall
metadata:
  name: my-firewall
  namespace: aws-networkfirewall-system
spec:
  region: eu-west-1
  # ... ACK Firewall spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsnetworkfirewallfirewalls.composition.krateo.io -n aws-networkfirewall-system
kubectl get firewalls.networkfirewall.services.k8s.aws -A
```
