# Krateo Blueprint — AWS Networkfirewall FirewallPolicy

> Generated by `tools/ackgen` from the ACK `FirewallPolicy` CRD (`networkfirewall.services.k8s.aws`).

Provisions an AWS Networkfirewall **FirewallPolicy** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
networkfirewall controller. The chart renders a native `networkfirewall.services.k8s.aws/v1alpha1` `FirewallPolicy`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsNetworkfirewallFirewallpolicy` Composition you create
becomes an AWS FirewallPolicy.

## Prerequisites

- **ACK networkfirewall controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-networkfirewall-controller \
    oci://public.ecr.aws/aws-controllers-k8s/networkfirewall-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK FirewallPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-networkfirewall-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsNetworkfirewallFirewallpolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsNetworkfirewallFirewallpolicy` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsnetworkfirewallfirewallpolicies`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-networkfirewall-firewallpolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsNetworkfirewallFirewallpolicy
metadata:
  name: my-firewallpolicy
  namespace: aws-networkfirewall-system
spec:
  region: eu-west-1
  # ... ACK FirewallPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsnetworkfirewallfirewallpolicies.composition.krateo.io -n aws-networkfirewall-system
kubectl get firewallpolicys.networkfirewall.services.k8s.aws -A
```
