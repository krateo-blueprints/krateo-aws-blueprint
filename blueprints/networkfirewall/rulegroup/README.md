# Krateo Blueprint — AWS Networkfirewall RuleGroup

> Generated by `tools/ackgen` from the ACK `RuleGroup` CRD (`networkfirewall.services.k8s.aws`).

Provisions an AWS Networkfirewall **RuleGroup** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
networkfirewall controller. The chart renders a native `networkfirewall.services.k8s.aws/v1alpha1` `RuleGroup`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsNetworkfirewallRulegroup` Composition you create
becomes an AWS RuleGroup.

## Prerequisites

- **ACK networkfirewall controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-networkfirewall-controller \
    oci://public.ecr.aws/aws-controllers-k8s/networkfirewall-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK RuleGroup spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-networkfirewall-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsNetworkfirewallRulegroup type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsNetworkfirewallRulegroup` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsnetworkfirewallrulegroups`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-networkfirewall-rulegroup`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsNetworkfirewallRulegroup
metadata:
  name: my-rulegroup
  namespace: aws-networkfirewall-system
spec:
  region: eu-west-1
  # ... ACK RuleGroup spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsnetworkfirewallrulegroups.composition.krateo.io -n aws-networkfirewall-system
kubectl get rulegroups.networkfirewall.services.k8s.aws -A
```
