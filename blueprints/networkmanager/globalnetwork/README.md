# Krateo Blueprint — AWS Networkmanager GlobalNetwork

> Generated by `tools/ackgen` from the ACK `GlobalNetwork` CRD (`networkmanager.services.k8s.aws`).

Provisions an AWS Networkmanager **GlobalNetwork** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
networkmanager controller. The chart renders a native `networkmanager.services.k8s.aws/v1alpha1` `GlobalNetwork`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsNetworkmanagerGlobalnetwork` Composition you create
becomes an AWS GlobalNetwork.

## Prerequisites

- **ACK networkmanager controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-networkmanager-controller \
    oci://public.ecr.aws/aws-controllers-k8s/networkmanager-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK GlobalNetwork spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-networkmanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsNetworkmanagerGlobalnetwork type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsNetworkmanagerGlobalnetwork` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsnetworkmanagerglobalnetworks`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-networkmanager-globalnetwork`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsNetworkmanagerGlobalnetwork
metadata:
  name: my-globalnetwork
  namespace: aws-networkmanager-system
spec:
  region: eu-west-1
  # ... ACK GlobalNetwork spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsnetworkmanagerglobalnetworks.composition.krateo.io -n aws-networkmanager-system
kubectl get globalnetworks.networkmanager.services.k8s.aws -A
```
