# Krateo Blueprint — AWS Opensearchserverless Collection

> Generated by `tools/ackgen` from the ACK `Collection` CRD (`opensearchserverless.services.k8s.aws`).

Provisions an AWS Opensearchserverless **Collection** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
opensearchserverless controller. The chart renders a native `opensearchserverless.services.k8s.aws/v1alpha1` `Collection`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsOpensearchserverlessCollection` Composition you create
becomes an AWS Collection.

## Prerequisites

- **ACK opensearchserverless controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-opensearchserverless-controller \
    oci://public.ecr.aws/aws-controllers-k8s/opensearchserverless-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Collection spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-opensearchserverless-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsOpensearchserverlessCollection type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsOpensearchserverlessCollection` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsopensearchserverlesscollections`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-opensearchserverless-collection`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsOpensearchserverlessCollection
metadata:
  name: my-collection
  namespace: aws-opensearchserverless-system
spec:
  region: eu-west-1
  # ... ACK Collection spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsopensearchserverlesscollections.composition.krateo.io -n aws-opensearchserverless-system
kubectl get collections.opensearchserverless.services.k8s.aws -A
```
