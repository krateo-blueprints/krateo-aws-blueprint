# Krateo Blueprint — AWS Opensearchserverless SecurityPolicy

> Generated by `tools/ackgen` from the ACK `SecurityPolicy` CRD (`opensearchserverless.services.k8s.aws`).

Provisions an AWS Opensearchserverless **SecurityPolicy** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
opensearchserverless controller. The chart renders a native `opensearchserverless.services.k8s.aws/v1alpha1` `SecurityPolicy`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsOpensearchserverlessSecuritypolicy` Composition you create
becomes an AWS SecurityPolicy.

## Prerequisites

- **ACK opensearchserverless controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-opensearchserverless-controller \
    oci://public.ecr.aws/aws-controllers-k8s/opensearchserverless-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK SecurityPolicy spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-opensearchserverless-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsOpensearchserverlessSecuritypolicy type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsOpensearchserverlessSecuritypolicy` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsopensearchserverlesssecuritypolicies`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-opensearchserverless-securitypolicy`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsOpensearchserverlessSecuritypolicy
metadata:
  name: my-securitypolicy
  namespace: aws-opensearchserverless-system
spec:
  region: eu-west-1
  # ... ACK SecurityPolicy spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsopensearchserverlesssecuritypolicies.composition.krateo.io -n aws-opensearchserverless-system
kubectl get securitypolicys.opensearchserverless.services.k8s.aws -A
```
