# Krateo Blueprint — AWS Opensearchservice Domain

> Generated by `tools/ackgen` from the ACK `Domain` CRD (`opensearchservice.services.k8s.aws`).

Provisions an AWS Opensearchservice **Domain** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
opensearchservice controller. The chart renders a native `opensearchservice.services.k8s.aws/v1alpha1` `Domain`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsOpensearchserviceDomain` Composition you create
becomes an AWS Domain.

## Prerequisites

- **ACK opensearchservice controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-opensearchservice-controller \
    oci://public.ecr.aws/aws-controllers-k8s/opensearchservice-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Domain spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-opensearchservice-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsOpensearchserviceDomain type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsOpensearchserviceDomain` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsopensearchservicedomains`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-opensearchservice-domain`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsOpensearchserviceDomain
metadata:
  name: my-domain
  namespace: aws-opensearchservice-system
spec:
  region: eu-west-1
  # ... ACK Domain spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsopensearchservicedomains.composition.krateo.io -n aws-opensearchservice-system
kubectl get domains.opensearchservice.services.k8s.aws -A
```
