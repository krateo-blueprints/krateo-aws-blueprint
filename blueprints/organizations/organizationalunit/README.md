# Krateo Blueprint — AWS Organizations OrganizationalUnit

> Generated by `tools/ackgen` from the ACK `OrganizationalUnit` CRD (`organizations.services.k8s.aws`).

Provisions an AWS Organizations **OrganizationalUnit** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
organizations controller. The chart renders a native `organizations.services.k8s.aws/v1alpha1` `OrganizationalUnit`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsOrganizationsOrganizationalunit` Composition you create
becomes an AWS OrganizationalUnit.

## Prerequisites

- **ACK organizations controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-organizations-controller \
    oci://public.ecr.aws/aws-controllers-k8s/organizations-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK OrganizationalUnit spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-organizations-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsOrganizationsOrganizationalunit type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsOrganizationsOrganizationalunit` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsorganizationsorganizationalunits`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-organizations-organizationalunit`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsOrganizationsOrganizationalunit
metadata:
  name: my-organizationalunit
  namespace: aws-organizations-system
spec:
  region: eu-west-1
  # ... ACK OrganizationalUnit spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsorganizationsorganizationalunits.composition.krateo.io -n aws-organizations-system
kubectl get organizationalunits.organizations.services.k8s.aws -A
```
