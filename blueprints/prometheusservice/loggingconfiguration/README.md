# Krateo Blueprint — AWS Prometheusservice LoggingConfiguration

> Generated by `tools/ackgen` from the ACK `LoggingConfiguration` CRD (`prometheusservice.services.k8s.aws`).

Provisions an AWS Prometheusservice **LoggingConfiguration** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
prometheusservice controller. The chart renders a native `prometheusservice.services.k8s.aws/v1alpha1` `LoggingConfiguration`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsPrometheusserviceLoggingconfiguration` Composition you create
becomes an AWS LoggingConfiguration.

## Prerequisites

- **ACK prometheusservice controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-prometheusservice-controller \
    oci://public.ecr.aws/aws-controllers-k8s/prometheusservice-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK LoggingConfiguration spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-prometheusservice-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsPrometheusserviceLoggingconfiguration type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsPrometheusserviceLoggingconfiguration` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsprometheusserviceloggingconfigurations`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-prometheusservice-loggingconfiguration`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsPrometheusserviceLoggingconfiguration
metadata:
  name: my-loggingconfiguration
  namespace: aws-prometheusservice-system
spec:
  region: eu-west-1
  # ... ACK LoggingConfiguration spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsprometheusserviceloggingconfigurations.composition.krateo.io -n aws-prometheusservice-system
kubectl get loggingconfigurations.prometheusservice.services.k8s.aws -A
```
