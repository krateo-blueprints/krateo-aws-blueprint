# Krateo Blueprint — AWS Quicksight DataSet

> Generated by `tools/ackgen` from the ACK `DataSet` CRD (`quicksight.services.k8s.aws`).

Provisions an AWS Quicksight **DataSet** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
quicksight controller. The chart renders a native `quicksight.services.k8s.aws/v1alpha1` `DataSet`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsQuicksightDataset` Composition you create
becomes an AWS DataSet.

## Prerequisites

- **ACK quicksight controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-quicksight-controller \
    oci://public.ecr.aws/aws-controllers-k8s/quicksight-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK DataSet spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-quicksight-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsQuicksightDataset type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsQuicksightDataset` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsquicksightdatasets`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-quicksight-dataset`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsQuicksightDataset
metadata:
  name: my-dataset
  namespace: aws-quicksight-system
spec:
  region: eu-west-1
  # ... ACK DataSet spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsquicksightdatasets.composition.krateo.io -n aws-quicksight-system
kubectl get datasets.quicksight.services.k8s.aws -A
```
