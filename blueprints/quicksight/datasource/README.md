# Krateo Blueprint — AWS Quicksight DataSource

> Generated by `tools/ackgen` from the ACK `DataSource` CRD (`quicksight.services.k8s.aws`).

Provisions an AWS Quicksight **DataSource** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
quicksight controller. The chart renders a native `quicksight.services.k8s.aws/v1alpha1` `DataSource`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsQuicksightDatasource` Composition you create
becomes an AWS DataSource.

## Prerequisites

- **ACK quicksight controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-quicksight-controller \
    oci://public.ecr.aws/aws-controllers-k8s/quicksight-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK DataSource spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-quicksight-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsQuicksightDatasource type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsQuicksightDatasource` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsquicksightdatasources`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-quicksight-datasource`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsQuicksightDatasource
metadata:
  name: my-datasource
  namespace: aws-quicksight-system
spec:
  region: eu-west-1
  # ... ACK DataSource spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsquicksightdatasources.composition.krateo.io -n aws-quicksight-system
kubectl get datasources.quicksight.services.k8s.aws -A
```
