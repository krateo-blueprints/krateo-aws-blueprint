# Krateo Blueprint — AWS Ram Permission

> Generated by `tools/ackgen` from the ACK `Permission` CRD (`ram.services.k8s.aws`).

Provisions an AWS Ram **Permission** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ram controller. The chart renders a native `ram.services.k8s.aws/v1alpha1` `Permission`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsRAMPermission` Composition you create
becomes an AWS Permission.

## Prerequisites

- **ACK ram controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ram-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ram-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Permission spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-ram-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsRAMPermission type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsRAMPermission` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsrampermissions`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-ram-permission`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsRAMPermission
metadata:
  name: my-permission
  namespace: aws-ram-system
spec:
  region: eu-west-1
  # ... ACK Permission spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsrampermissions.composition.krateo.io -n aws-ram-system
kubectl get permissions.ram.services.k8s.aws -A
```
