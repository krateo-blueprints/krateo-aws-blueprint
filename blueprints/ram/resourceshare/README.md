# Krateo Blueprint — AWS Ram ResourceShare

> Generated by `tools/ackgen` from the ACK `ResourceShare` CRD (`ram.services.k8s.aws`).

Provisions an AWS Ram **ResourceShare** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ram controller. The chart renders a native `ram.services.k8s.aws/v1alpha1` `ResourceShare`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsRAMResourceshare` Composition you create
becomes an AWS ResourceShare.

## Prerequisites

- **ACK ram controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ram-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ram-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ResourceShare spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-ram-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsRAMResourceshare type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsRAMResourceshare` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsramresourceshares`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-ram-resourceshare`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsRAMResourceshare
metadata:
  name: my-resourceshare
  namespace: aws-ram-system
spec:
  region: eu-west-1
  # ... ACK ResourceShare spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsramresourceshares.composition.krateo.io -n aws-ram-system
kubectl get resourceshares.ram.services.k8s.aws -A
```
