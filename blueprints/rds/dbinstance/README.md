# Krateo Blueprint — AWS Rds DBInstance

> Generated by `tools/ackgen` from the ACK `DBInstance` CRD (`rds.services.k8s.aws`).

Provisions an AWS Rds **DBInstance** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
rds controller. The chart renders a native `rds.services.k8s.aws/v1alpha1` `DBInstance`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsRdsDbinstance` Composition you create
becomes an AWS DBInstance.

## Prerequisites

- **ACK rds controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-rds-controller \
    oci://public.ecr.aws/aws-controllers-k8s/rds-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK DBInstance spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-rds-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsRdsDbinstance type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsRdsDbinstance` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsrdsdbinstances`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-rds-dbinstance`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsRdsDbinstance
metadata:
  name: my-dbinstance
  namespace: aws-rds-system
spec:
  region: eu-west-1
  # ... ACK DBInstance spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsrdsdbinstances.composition.krateo.io -n aws-rds-system
kubectl get dbinstances.rds.services.k8s.aws -A
```
