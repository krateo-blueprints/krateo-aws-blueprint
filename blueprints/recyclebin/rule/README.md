# Krateo Blueprint — AWS Recyclebin Rule

> Generated by `tools/ackgen` from the ACK `Rule` CRD (`recyclebin.services.k8s.aws`).

Provisions an AWS Recyclebin **Rule** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
recyclebin controller. The chart renders a native `recyclebin.services.k8s.aws/v1alpha1` `Rule`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsRecyclebinRule` Composition you create
becomes an AWS Rule.

## Prerequisites

- **ACK recyclebin controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-recyclebin-controller \
    oci://public.ecr.aws/aws-controllers-k8s/recyclebin-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Rule spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-recyclebin-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsRecyclebinRule type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsRecyclebinRule` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsrecyclebinrules`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-recyclebin-rule`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsRecyclebinRule
metadata:
  name: my-rule
  namespace: aws-recyclebin-system
spec:
  region: eu-west-1
  # ... ACK Rule spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsrecyclebinrules.composition.krateo.io -n aws-recyclebin-system
kubectl get rules.recyclebin.services.k8s.aws -A
```
