# Krateo Blueprint — AWS Route53 HealthCheck

> Generated by `tools/ackgen` from the ACK `HealthCheck` CRD (`route53.services.k8s.aws`).

Provisions an AWS Route53 **HealthCheck** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
route53 controller. The chart renders a native `route53.services.k8s.aws/v1alpha1` `HealthCheck`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsRoute53Healthcheck` Composition you create
becomes an AWS HealthCheck.

## Prerequisites

- **ACK route53 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-route53-controller \
    oci://public.ecr.aws/aws-controllers-k8s/route53-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK HealthCheck spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-route53-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsRoute53Healthcheck type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsRoute53Healthcheck` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsroute53healthchecks`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-route53-healthcheck`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsRoute53Healthcheck
metadata:
  name: my-healthcheck
  namespace: aws-route53-system
spec:
  region: eu-west-1
  # ... ACK HealthCheck spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsroute53healthchecks.composition.krateo.io -n aws-route53-system
kubectl get healthchecks.route53.services.k8s.aws -A
```
