# Krateo Blueprint — AWS Route53 RecordSet

> Generated by `tools/ackgen` from the ACK `RecordSet` CRD (`route53.services.k8s.aws`).

Provisions an AWS Route53 **RecordSet** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
route53 controller. The chart renders a native `route53.services.k8s.aws/v1alpha1` `RecordSet`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsRoute53Recordset` Composition you create
becomes an AWS RecordSet.

## Prerequisites

- **ACK route53 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-route53-controller \
    oci://public.ecr.aws/aws-controllers-k8s/route53-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK RecordSet spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-route53-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsRoute53Recordset type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsRoute53Recordset` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsroute53recordsets`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-route53-recordset`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsRoute53Recordset
metadata:
  name: my-recordset
  namespace: aws-route53-system
spec:
  region: eu-west-1
  # ... ACK RecordSet spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsroute53recordsets.composition.krateo.io -n aws-route53-system
kubectl get recordsets.route53.services.k8s.aws -A
```
