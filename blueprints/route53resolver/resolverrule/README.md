# Krateo Blueprint — AWS Route53resolver ResolverRule

> Generated by `tools/ackgen` from the ACK `ResolverRule` CRD (`route53resolver.services.k8s.aws`).

Provisions an AWS Route53resolver **ResolverRule** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
route53resolver controller. The chart renders a native `route53resolver.services.k8s.aws/v1alpha1` `ResolverRule`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsRoute53resolverResolverrule` Composition you create
becomes an AWS ResolverRule.

## Prerequisites

- **ACK route53resolver controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-route53resolver-controller \
    oci://public.ecr.aws/aws-controllers-k8s/route53resolver-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ResolverRule spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-route53resolver-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsRoute53resolverResolverrule type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsRoute53resolverResolverrule` Composition type (`composition.krateo.io/v0-1-0`,
plural `awsroute53resolverresolverrules`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-route53resolver-resolverrule`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsRoute53resolverResolverrule
metadata:
  name: my-resolverrule
  namespace: aws-route53resolver-system
spec:
  region: eu-west-1
  # ... ACK ResolverRule spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsroute53resolverresolverrules.composition.krateo.io -n aws-route53resolver-system
kubectl get resolverrules.route53resolver.services.k8s.aws -A
```
