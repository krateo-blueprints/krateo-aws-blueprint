# Krateo Blueprint — AWS S3control AccessPoint

> Generated by `tools/ackgen` from the ACK `AccessPoint` CRD (`s3control.services.k8s.aws`).

Provisions an AWS S3control **AccessPoint** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
s3control controller. The chart renders a native `s3control.services.k8s.aws/v1alpha1` `AccessPoint`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsS3controlAccesspoint` Composition you create
becomes an AWS AccessPoint.

## Prerequisites

- **ACK s3control controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-s3control-controller \
    oci://public.ecr.aws/aws-controllers-k8s/s3control-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK AccessPoint spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-s3control-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-s3control-accesspoint.yaml"   # publishes the AwsS3controlAccesspoint type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsS3controlAccesspoint` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awss3controlaccesspoints`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-s3control-accesspoint` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsS3controlAccesspoint
metadata:
  name: my-accesspoint
  namespace: aws-s3control-system
spec:
  region: eu-west-1
  # ... ACK AccessPoint spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awss3controlaccesspoints.composition.krateo.io -n aws-s3control-system
kubectl get accesspoints.s3control.services.k8s.aws -A
```
