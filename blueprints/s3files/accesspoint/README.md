# Krateo Blueprint — AWS S3files AccessPoint

> Generated by `tools/ackgen` from the ACK `AccessPoint` CRD (`s3files.services.k8s.aws`).

Provisions an AWS S3files **AccessPoint** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
s3files controller. The chart renders a native `s3files.services.k8s.aws/v1alpha1` `AccessPoint`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsS3filesAccesspoint` Composition you create
becomes an AWS AccessPoint.

## Prerequisites

- **ACK s3files controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-s3files-controller \
    oci://public.ecr.aws/aws-controllers-k8s/s3files-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK AccessPoint spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-s3files-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsS3filesAccesspoint type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsS3filesAccesspoint` Composition type (`composition.krateo.io/v0-1-1`,
plural `awss3filesaccesspoints`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-s3files-accesspoint`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsS3filesAccesspoint
metadata:
  name: my-accesspoint
  namespace: aws-s3files-system
spec:
  region: eu-west-1
  # ... ACK AccessPoint spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awss3filesaccesspoints.composition.krateo.io -n aws-s3files-system
kubectl get accesspoints.s3files.services.k8s.aws -A
```
