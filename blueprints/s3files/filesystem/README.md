# Krateo Blueprint — AWS S3files FileSystem

> Generated by `tools/ackgen` from the ACK `FileSystem` CRD (`s3files.services.k8s.aws`).

Provisions an AWS S3files **FileSystem** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
s3files controller. The chart renders a native `s3files.services.k8s.aws/v1alpha1` `FileSystem`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsS3filesFilesystem` Composition you create
becomes an AWS FileSystem.

## Prerequisites

- **ACK s3files controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-s3files-controller \
    oci://public.ecr.aws/aws-controllers-k8s/s3files-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK FileSystem spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-s3files-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsS3filesFilesystem type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsS3filesFilesystem` Composition type (`composition.krateo.io/v0-1-1`,
plural `awss3filesfilesystems`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-s3files-filesystem`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsS3filesFilesystem
metadata:
  name: my-filesystem
  namespace: aws-s3files-system
spec:
  region: eu-west-1
  # ... ACK FileSystem spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awss3filesfilesystems.composition.krateo.io -n aws-s3files-system
kubectl get filesystems.s3files.services.k8s.aws -A
```
