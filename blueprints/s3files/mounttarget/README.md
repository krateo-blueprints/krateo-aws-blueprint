# Krateo Blueprint — AWS S3files MountTarget

> Generated by `tools/ackgen` from the ACK `MountTarget` CRD (`s3files.services.k8s.aws`).

Provisions an AWS S3files **MountTarget** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
s3files controller. The chart renders a native `s3files.services.k8s.aws/v1alpha1` `MountTarget`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsS3filesMounttarget` Composition you create
becomes an AWS MountTarget.

## Prerequisites

- **ACK s3files controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-s3files-controller \
    oci://public.ecr.aws/aws-controllers-k8s/s3files-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK MountTarget spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-s3files-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-s3files-mounttarget.yaml"   # publishes the AwsS3filesMounttarget type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsS3filesMounttarget` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awss3filesmounttargets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-s3files-mounttarget` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsS3filesMounttarget
metadata:
  name: my-mounttarget
  namespace: aws-s3files-system
spec:
  region: eu-west-1
  # ... ACK MountTarget spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awss3filesmounttargets.composition.krateo.io -n aws-s3files-system
kubectl get mounttargets.s3files.services.k8s.aws -A
```
