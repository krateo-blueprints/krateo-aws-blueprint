# Krateo Blueprint — AWS Sagemaker Endpoint

> Generated by `tools/ackgen` from the ACK `Endpoint` CRD (`sagemaker.services.k8s.aws`).

Provisions an AWS Sagemaker **Endpoint** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
sagemaker controller. The chart renders a native `sagemaker.services.k8s.aws/v1alpha1` `Endpoint`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSagemakerEndpoint` Composition you create
becomes an AWS Endpoint.

## Prerequisites

- **ACK sagemaker controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-sagemaker-controller \
    oci://public.ecr.aws/aws-controllers-k8s/sagemaker-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Endpoint spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-sagemaker-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsSagemakerEndpoint type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSagemakerEndpoint` Composition type (`composition.krateo.io/v0-1-1`,
plural `awssagemakerendpoints`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-sagemaker-endpoint`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsSagemakerEndpoint
metadata:
  name: my-endpoint
  namespace: aws-sagemaker-system
spec:
  region: eu-west-1
  # ... ACK Endpoint spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awssagemakerendpoints.composition.krateo.io -n aws-sagemaker-system
kubectl get endpoints.sagemaker.services.k8s.aws -A
```
