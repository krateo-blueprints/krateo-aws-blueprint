# Krateo Blueprint — AWS Sagemaker ModelQualityJobDefinition

> Generated by `tools/ackgen` from the ACK `ModelQualityJobDefinition` CRD (`sagemaker.services.k8s.aws`).

Provisions an AWS Sagemaker **ModelQualityJobDefinition** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
sagemaker controller. The chart renders a native `sagemaker.services.k8s.aws/v1alpha1` `ModelQualityJobDefinition`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSagemakerModelqualityjobdefinition` Composition you create
becomes an AWS ModelQualityJobDefinition.

## Prerequisites

- **ACK sagemaker controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-sagemaker-controller \
    oci://public.ecr.aws/aws-controllers-k8s/sagemaker-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ModelQualityJobDefinition spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-sagemaker-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsSagemakerModelqualityjobdefinition type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSagemakerModelqualityjobdefinition` Composition type (`composition.krateo.io/v0-1-0`,
plural `awssagemakermodelqualityjobdefinitions`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-sagemaker-modelqualityjobdefinition`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-0
kind: AwsSagemakerModelqualityjobdefinition
metadata:
  name: my-modelqualityjobdefinition
  namespace: aws-sagemaker-system
spec:
  region: eu-west-1
  # ... ACK ModelQualityJobDefinition spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awssagemakermodelqualityjobdefinitions.composition.krateo.io -n aws-sagemaker-system
kubectl get modelqualityjobdefinitions.sagemaker.services.k8s.aws -A
```
