# Krateo Blueprint — AWS Secretsmanager Secret

> Generated by `tools/ackgen` from the ACK `Secret` CRD (`secretsmanager.services.k8s.aws`).

Provisions an AWS Secretsmanager **Secret** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
secretsmanager controller. The chart renders a native `secretsmanager.services.k8s.aws/v1alpha1` `Secret`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSecretsmanagerSecret` Composition you create
becomes an AWS Secret.

## Prerequisites

- **ACK secretsmanager controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-secretsmanager-controller \
    oci://public.ecr.aws/aws-controllers-k8s/secretsmanager-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Secret spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-secretsmanager-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsSecretsmanagerSecret type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSecretsmanagerSecret` Composition type (`composition.krateo.io/v0-1-1`,
plural `awssecretsmanagersecrets`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-secretsmanager-secret`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsSecretsmanagerSecret
metadata:
  name: my-secret
  namespace: aws-secretsmanager-system
spec:
  region: eu-west-1
  # ... ACK Secret spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awssecretsmanagersecrets.composition.krateo.io -n aws-secretsmanager-system
kubectl get secrets.secretsmanager.services.k8s.aws -A
```
