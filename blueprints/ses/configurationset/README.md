# Krateo Blueprint — AWS Ses ConfigurationSet

> Generated by `tools/ackgen` from the ACK `ConfigurationSet` CRD (`ses.services.k8s.aws`).

Provisions an AWS Ses **ConfigurationSet** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ses controller. The chart renders a native `ses.services.k8s.aws/v1alpha1` `ConfigurationSet`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSesConfigurationset` Composition you create
becomes an AWS ConfigurationSet.

## Prerequisites

- **ACK ses controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ses-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ses-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK ConfigurationSet spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-ses-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsSesConfigurationset type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSesConfigurationset` Composition type (`composition.krateo.io/v0-1-1`,
plural `awssesconfigurationsets`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-ses-configurationset`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsSesConfigurationset
metadata:
  name: my-configurationset
  namespace: aws-ses-system
spec:
  region: eu-west-1
  # ... ACK ConfigurationSet spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awssesconfigurationsets.composition.krateo.io -n aws-ses-system
kubectl get configurationsets.ses.services.k8s.aws -A
```
