# Krateo Blueprint — AWS Sfn Activity

> Generated by `tools/ackgen` from the ACK `Activity` CRD (`sfn.services.k8s.aws`).

Provisions an AWS Sfn **Activity** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
sfn controller. The chart renders a native `sfn.services.k8s.aws/v1alpha1` `Activity`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSfnActivity` Composition you create
becomes an AWS Activity.

## Prerequisites

- **ACK sfn controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-sfn-controller \
    oci://public.ecr.aws/aws-controllers-k8s/sfn-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Activity spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-sfn-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsSfnActivity type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSfnActivity` Composition type (`composition.krateo.io/v0-1-1`,
plural `awssfnactivities`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-sfn-activity`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsSfnActivity
metadata:
  name: my-activity
  namespace: aws-sfn-system
spec:
  region: eu-west-1
  # ... ACK Activity spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awssfnactivities.composition.krateo.io -n aws-sfn-system
kubectl get activitys.sfn.services.k8s.aws -A
```
