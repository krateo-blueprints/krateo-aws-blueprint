# Krateo Blueprint — AWS Sfn StateMachine

> Generated by `tools/ackgen` from the ACK `StateMachine` CRD (`sfn.services.k8s.aws`).

Provisions an AWS Sfn **StateMachine** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
sfn controller. The chart renders a native `sfn.services.k8s.aws/v1alpha1` `StateMachine`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSfnStatemachine` Composition you create
becomes an AWS StateMachine.

## Prerequisites

- **ACK sfn controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-sfn-controller \
    oci://public.ecr.aws/aws-controllers-k8s/sfn-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK StateMachine spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-sfn-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-sfn-statemachine.yaml"   # publishes the AwsSfnStatemachine type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSfnStatemachine` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awssfnstatemachines`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-sfn-statemachine` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsSfnStatemachine
metadata:
  name: my-statemachine
  namespace: aws-sfn-system
spec:
  region: eu-west-1
  # ... ACK StateMachine spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awssfnstatemachines.composition.krateo.io -n aws-sfn-system
kubectl get statemachines.sfn.services.k8s.aws -A
```
