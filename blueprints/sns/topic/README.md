# Krateo Blueprint — AWS Sns Topic

> Generated by `tools/ackgen` from the ACK `Topic` CRD (`sns.services.k8s.aws`).

Provisions an AWS Sns **Topic** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
sns controller. The chart renders a native `sns.services.k8s.aws/v1alpha1` `Topic`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSnsTopic` Composition you create
becomes an AWS Topic.

## Prerequisites

- **ACK sns controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-sns-controller \
    oci://public.ecr.aws/aws-controllers-k8s/sns-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Topic spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-sns-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsSnsTopic type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSnsTopic` Composition type (`composition.krateo.io/v0-1-1`,
plural `awssnstopics`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-sns-topic`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsSnsTopic
metadata:
  name: my-topic
  namespace: aws-sns-system
spec:
  region: eu-west-1
  # ... ACK Topic spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awssnstopics.composition.krateo.io -n aws-sns-system
kubectl get topics.sns.services.k8s.aws -A
```
