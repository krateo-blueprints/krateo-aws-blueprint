# Krateo Blueprint — AWS Sqs Queue

> Generated by `tools/ackgen` from the ACK `Queue` CRD (`sqs.services.k8s.aws`).

Provisions an AWS Sqs **Queue** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
sqs controller. The chart renders a native `sqs.services.k8s.aws/v1alpha1` `Queue`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSqsQueue` Composition you create
becomes an AWS Queue.

## Prerequisites

- **ACK sqs controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-sqs-controller \
    oci://public.ecr.aws/aws-controllers-k8s/sqs-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK Queue spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-sqs-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsSqsQueue type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSqsQueue` Composition type (`composition.krateo.io/v0-1-1`,
plural `awssqsqueues`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-sqs-queue`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsSqsQueue
metadata:
  name: my-queue
  namespace: aws-sqs-system
spec:
  region: eu-west-1
  # ... ACK Queue spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awssqsqueues.composition.krateo.io -n aws-sqs-system
kubectl get queues.sqs.services.k8s.aws -A
```
