# Krateo Blueprint — AWS Ssm PatchBaseline

> Generated by `tools/ackgen` from the ACK `PatchBaseline` CRD (`ssm.services.k8s.aws`).

Provisions an AWS Ssm **PatchBaseline** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
ssm controller. The chart renders a native `ssm.services.k8s.aws/v1alpha1` `PatchBaseline`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsSsmPatchbaseline` Composition you create
becomes an AWS PatchBaseline.

## Prerequisites

- **ACK ssm controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-ssm-controller \
    oci://public.ecr.aws/aws-controllers-k8s/ssm-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK PatchBaseline spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

```sh
kubectl create namespace aws-ssm-system
kubectl apply -f compositiondefinition.yaml   # publishes the AwsSsmPatchbaseline type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsSsmPatchbaseline` Composition type (`composition.krateo.io/v0-1-1`,
plural `awsssmpatchbaselines`), pulling the chart from
`oci://ghcr.io/braghettos/charts/aws-ssm-patchbaseline`.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/v0-1-1
kind: AwsSsmPatchbaseline
metadata:
  name: my-patchbaseline
  namespace: aws-ssm-system
spec:
  region: eu-west-1
  # ... ACK PatchBaseline spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awsssmpatchbaselines.composition.krateo.io -n aws-ssm-system
kubectl get patchbaselines.ssm.services.k8s.aws -A
```
