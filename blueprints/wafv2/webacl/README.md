# Krateo Blueprint — AWS Wafv2 WebACL

> Generated by `tools/ackgen` from the ACK `WebACL` CRD (`wafv2.services.k8s.aws`).

Provisions an AWS Wafv2 **WebACL** through the
[AWS Controllers for Kubernetes (ACK)](https://aws-controllers-k8s.github.io/community/)
wafv2 controller. The chart renders a native `wafv2.services.k8s.aws/v1alpha1` `WebACL`
resource; the ACK controller reconciles it into the real AWS resource and reports status back.

Once the `CompositionDefinition` is applied, every `AwsWafv2Webacl` Composition you create
becomes an AWS WebACL.

## Prerequisites

- **ACK wafv2 controller installed** — see
  [`../../../docs/installing-controllers.md`](../../../docs/installing-controllers.md):
  ```sh
  helm install ack-wafv2-controller \
    oci://public.ecr.aws/aws-controllers-k8s/wafv2-chart \
    --namespace ack-system --create-namespace \
    --set aws.region=eu-west-1
  ```
- **AWS credentials configured** on that controller (IRSA/Pod Identity or static) — see
  [`../../../docs/authentication.md`](../../../docs/authentication.md).
- Krateo `core-provider` installed.

## Configuration

Composition `spec` fields **mirror the ACK WebACL spec**. Full schema in
[`chart/values.schema.json`](chart/values.schema.json). The extra `region` field selects the
AWS region (empty = controller default).

## How to install

Register it with the CompositionDefinition attached to a release of this repository, stamped
with that release's chart version. The `compositiondefinition.yaml` beside this README carries
the `CHART_VERSION` placeholder, which only the release replaces, so it is not meant to be applied.

```sh
VERSION=X.Y.Z   # a release of this repository: https://github.com/krateo-blueprints/krateo-aws-blueprint/releases
kubectl create namespace aws-wafv2-system
kubectl apply -f "https://github.com/krateo-blueprints/krateo-aws-blueprint/releases/download/${VERSION}/compositiondefinition-aws-wafv2-webacl.yaml"   # publishes the AwsWafv2Webacl type
kubectl apply -f customform.yaml              # optional: portal card + form
```

This publishes a `AwsWafv2Webacl` Composition type (`composition.krateo.io/vX-Y-Z`, the release
version with dashes, e.g. `0.1.6` → `v0-1-6`; plural `awswafv2webacls`), pulling the chart from
`oci://ghcr.io/krateo-blueprints/charts/aws-wafv2-webacl` at that version.

### Create a Composition

```yaml
apiVersion: composition.krateo.io/vX-Y-Z   # VERSION with dashes, e.g. v0-1-6
kind: AwsWafv2Webacl
metadata:
  name: my-webacl
  namespace: aws-wafv2-system
spec:
  region: eu-west-1
  # ... ACK WebACL spec fields (see values.schema.json)
```

### Check status

```sh
kubectl get awswafv2webacls.composition.krateo.io -n aws-wafv2-system
kubectl get webacls.wafv2.services.k8s.aws -A
```
